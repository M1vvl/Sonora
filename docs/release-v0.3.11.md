## 模块与统计

`ui/token-activity-model.js` 是独立纯模型，按北京时间日期字符串处理日历，避免本地时区/DST 错位。`token-activity.js/css` 仅管理热图 DOM 与交互；无网络、日志扫描、后台轮询或图表依赖。dashboard 只把已有 dailyUsage、今天和总量传入；同值快照跳过绘制，更新保留方格节点、焦点与用户滚动位置。

默认展示当前月份及之前十一个月。每日模式每格一天，过去填零、未来/边界填充格不可选。每周模式每列七格展示同一个完整周总量，当前周明确截至今天。累计模式每列七格展示截至周末（当前周截至今天）的全部有效日期历史累计，并保留更早历史基线。缺少日期的差值不伪造到某日，通过说明按钮解释。该图反映本机已能读取的日志，原日志缺失不能凭空恢复。

每列方格保持至少 6px、间隔 2px；窄列横向滚动查看全部十二个月，默认定位最近月份。模式/数据更新保留滚动位置。无随机填充，没有把未知金额或无日期用量涂成活动。

主题定义不变，热图色阶从当前主题变量派生。边框对齐覆盖每日/完整历史、明细展开/收起和最小 960×660 窗口。正式配置与诊断目录隔离，用户预览读取实际保存的主题。
