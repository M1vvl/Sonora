## 仍不能称为整个 MineRadio 完整 1:1

本次已复用原歌词/粒子/场景核心，六个页签的所有扩展功能仍未完整迁移：独立桌面歌词、上传字体/自定义歌词编辑、多命名视觉存档、完整 cinema/free-camera 与摄像头联动、原 Three.js 歌单架和系统修改页/待机页清理等。现有歌单架仍是共用业务的 CSS perspective 适配，内存管理仅回收本软件工作集。具体差异见 `assets/music/source-presets/lyrics-source/INTEGRATION.md`，不将源码中存在的辅助函数算作对应 UI 已接通。

其他音乐平台按用户允许的“遇到阻碍先跳过”处理；目前完整账号/歌单/播放链路仍只有网易云。各平台实际阻碍见 `v021-platform-integration.md`。没有把预留按钮或单纯打开网页登录页称为已完成接入。
