# 0.3.4：总览统一与桌面窗口整理

日期：2026-10-28。

## 变更

- 灵动岛历史统计改为四个等宽网格列，每列标签与数值共用中心轴；金额维持原有重点色。
- 监控面板只保留总览与设置两个导航项。项目与对话、搜索、Agent 筛选、历史 / 每日统计、详情和导出继续由总览提供，删除重复的会话视图逻辑。
- 删除侧栏下半部分本地说明、计价卡与版本信息，以及顶栏路径和运行提示。对应 DOM 引用和专用死样式一并移除，保留实际统计与设置中的价格信息。
- 三个窗口按钮统一使用矢量图形与固定点击区域，图形在水平和垂直方向居中。顶部空白区域继续支持拖动。
- 托盘单击即可打开监控面板；双击、右键菜单和再次启动桌面快捷方式仍可打开。后台初始化期间收到的打开请求先记录，在窗口可显示后恢复并聚焦；重复请求复用同一窗口。关闭面板释放渲染进程，托盘与监控继续运行。

## 范围与维护

本次仅调整界面结构、布局和面板入口，不修改日志索引、用量计算、音频或封面协议。沿用用户选择的清透材质，不改变 Windows 全局透明效果设置。

## 验证与发布

61 项 Node 单元检查通过。打包成品的 51 项交互检查全部通过，渲染错误为 0；报告位于 `artifacts/v0.3.4-packaged/smoke-report.json`，面板和岛截图位于同目录。新增检查覆盖总览内项目对话搜索 / 筛选 / 详情、冗余结构移除、三个窗口图形的实际几何居中、四列等宽且标签 / 数值居中。

实际安装测试：仅灵动岛后台运行时再次启动 EXE，面板出现；点击关闭按钮后面板窗口销毁而岛继续运行；再次启动桌面 `Agent Pulse.lnk` 成功重建面板，主进程 PID 保持 25556，没有留下第二个主实例。托盘单击与双击共用同一打开入口，静态审查确认早到请求保留和关闭后重建路径。

已通过 `npm run release` 完成替换，核对安装版为 0.3.4.0。新版启动成功后仅保留 0.3.4 与 0.3.3 的便携 EXE，已删除 0.3.2 便携 EXE；用户数据和分析记录不在清理范围内。
