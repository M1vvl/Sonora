## 真实验证与限制

源码新用户场景实测电影《流浪地球》：真实推荐封面、全库搜索、如意来源分集、原生播放、过滤回环、返回释放、续播及两个进程的历史恢复。证据 `artifacts/v0.3.14-movies`，全部使用隔离配置，不复制开发者观看历史。

REA 分析与默认源清单、实际 HLS 清单/分片请求的区别记录在 `libretv-source-analysis.md`。Docker 是上游网站部署选择，桌面使用不需要额外部署；全部 JavaScript 和 Windows 音视频运行组件随便携包交付。

默认多源和退避提高容错，无法保证外部内容服务永久可用。普通 HLS 时间边界与广告不能总是区分，过滤是保守策略且可关闭。没有宣称已在每种 Windows、显卡和网络上完成干净虚拟机测试；本次完成空白配置与随包依赖核查及本机真实视频运行。
