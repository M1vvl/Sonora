# 0.3.2：灵动岛排版与实时消息替换

日期：2026-10-28。

- 删除展开底部的今日 Token 和打开监控面板整栏。托盘与桌面快捷方式仍可打开主面板。
- 将顶部 Agent / 状态和当前活动两行置于胶囊水平与垂直中部，限制文本宽度并保留左右封面、金额空间。
- 普通标签、选择框和正文增大约 2–3px（约 1.5–2pt），改用冷白与冰蓝；金额和 Token 仍为荧光色视觉重点。
- 新消息使用 220ms 的向上退出 / 进入替换，仅改变 transform 和 opacity。没有循环滚播。独立玻璃圆角视口高 82px，阅读区高 60px，长文本可手动滚动。
- 首次载入只显示最新；同 ID 流式文本原地更新；队列最多 6 条、去重记录最多 128 条。收起 / 隐藏 / 切会话取消旧动画，异步完成不会覆盖新会话。
- 过渡中的文本高度限制为视口高度，避免长段落按自身高度移动数百像素。过渡完成后恢复自然高度供滚动。
- 预览去掉 Markdown 标记和内部 annotation 指令，保留原始日志和计价数据。

模块分别位于 `ui/activity-feed.js`、`ui/activity-feed.css`、`ui/text-preview.js`。主视图仅传递当前会话的最近 6 条安全展示事件。窗口尺寸集中在 `src/window-layout.cjs`，收起 480×44、展开 520×272；CSS 页面随原生视口填满。

用户明确要求消息上滑，因此默认 `activityMotion=scroll`；另提供 system / still 手动偏好，system 遵从系统减少动态效果，不修改 Windows 设置。透明材质继续使用用户选择的清透降级，不宣称该 CSS 框具有跨桌面原生磨砂能力。

验证：52 项 Node 单元检查通过；Electron 源码检查覆盖排版居中、字号、重点颜色分离、移除旧底栏、上滑动画、长文本位移限制 / 手动滚动、收起清理和预览清理，全部通过。成品结果见 `artifacts/v0.3.2-packaged/smoke-report.json`；发布按固定流程保留 0.3.2 与 0.3.1 两版便携 EXE。
