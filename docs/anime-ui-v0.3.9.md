## Kazumi Windows 源码依据

`lib/pages/search/search_page.dart` 的 `_loadMoreOnScroll` 在剩余滚动距离不超过 360px 时加载，查询使用 `_submittedQuery`；`lib/pages/popular/popular_page.dart` 则在距离底部 200px 时按趋势或分类继续。此处迁移为浏览器滚动根节点的观察器加被动 scroll 监听，不需要移动端控制器。

`lib/pages/history/history_list_view.dart` 依据实际传入的 entries 构建历史列表；本次将 Agent Pulse 已经保存的记录通过持久化事件同步到当前视图，未添加点击条目即生成历史的逻辑。
