# 0.3.17 影视卡片与自动找源核对

## 对应需求

- 原主页宽幅单张主视觉替换为多张竖向圆角金属卡片；保留原下方四张精选和左侧热门、继续观看。顶区310px，实际竖卡252px，低于旧横幅主视觉高度。960/1260/1536宽度均在内容区域内，右侧导航不被覆盖。
- 整张卡片区域可左右拖动，超过6px才认定水平意图；竖向移动交还页面。指针捕获、释放速度、有限惯性与点击抑制由独立 `ui/movies/carousel.js` 负责。普通点击进入详情，拖动不会误打开；键盘方向/Home/End和触控原生横向滚动保留。
- 在接近右边缘时按需追加随机高分电影。`src/movies/recommendations.cjs` 仅把新批次洗牌后追加，评分必须>=7.5。旧节点、电影身份与顺序均不改变；向右拖回仍是先前电影。一次访问最多120条，最多每手势读取三页，稀疏/断网时提供明确重试，不启动无限后台请求。
- 使用豆瓣真实 `type=movie&tag=豆瓣高分` 目录；不使用无效的“高分”标签，后者曾混入剧集。接口不可用时退回既有电影分类，仍不补造评分。实际请求首批12部，评分7.5以上；影片可播放性由详情搜索到的真实来源决定，评分不是播放证明。
- 影视详情加载后自动按已启用片源查找并验证分集，最多三个来源同时查询。保留“查找播放源”按钮用于刷新，查询过程中禁用重复请求；初始自动找源不直接播放。切换影片/导航/关闭后，迟到结果不得覆盖新页面。
- 样式沿用当前整套主题，不增加WebGL或常驻动画循环；惯性停稳、导航停用和销毁均释放帧/监听。元数据、来源验证、播放与封面加载保持各自职责。

## 实现边界

- `ui/movies/carousel.js/css`：横向滚动、手势、金属边缘和追加展示；同一访问内保留已浏览的DOM与顺序。
- `src/movies/recommendations.cjs`：追加顺序、随机新批次、去重、评分过滤、分页与120项上限。
- `src/movies/index.cjs`：复用既有有界网络与目录解析，新增recommendations动作；不引入另一套来源协议或播放器。
- `ui/anime/index.js`：只在movies模式替换主视觉与自动找源。番剧原五张布局和显式找源流程维持；双方复用 `ui/cover-loading.js` 的封面优先级和生命周期。

## 成品复核追加：单个来源误取消整个聚合

暂存成品复测曾在搜索后显示 `The operation was aborted`；同一诊断随即直接查询目录仍返回11条，其他来源状态为available。原因是Electron把合并信号中的单源超时表现为DOM `AbortError`，聚合器把它当成全局导航取消，丢弃了其他来源的有效结果。

已在 `src/movies/index.cjs` 的单源上下文边界修复：仅generation改变或服务退出才传播全局取消；当前generation的单源AbortError规范为该源失败，保留自身TimeoutError原因，继续收集其他来源。对应回归用一源抛DOMAbortError、另一源返回真实形态结果，验证不再整体拒绝；原导航取消回归仍通过。30项影视服务/分类/UI/推荐/卡片检查通过。

诊断脚本新增显式completed标记；中途退出不能只因没有error字段而误报完成。还在独立画质验证前等待自动找源完成，避免诊断自身并发请求争用网络槽位。质量仍必须取得真实尺寸才能通过，未放宽标准。最终打包必须使用包含该修复的新构建。
