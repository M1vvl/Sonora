# 0.3.6：去除硬相框，连续柔化玻璃边缘

日期：2026-10-29。

## 问题定位

0.3.5 的主轮廓、四层 inset 阴影、主体伪元素描边、3px 锥形高光环和另一组内描边叠在一起，形成平行硬线。与此同时，实时取样环带中间的 alpha 接近 255，覆盖了真实背景；固定 2 个物理像素的内沿渐隐在高 DPI 下更窄。结果像贴上的相框，而非有体积的玻璃。

## 参考代码的含义与桌面限制

用户图片里的 `blur(28px)` 柔化背景，`saturate(170%)` 调整颜色，白色低透明度背景形成散射罩层，inset 阴影提供方向性高光；这些和 SVG 位移各自承担不同职责。根据 [SVG 位移文档](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feDisplacementMap)，位移使用另一张图的通道来改变输入图像的取样位置，不能自动取得未知的桌面像素，也不等同于模糊。

[Apple 的 Liquid Glass 说明](https://developer.apple.com/videos/play/wwdc2025/219/) 强调透镜、方向性高光、层次和随上下文变化的清晰度；扩大材质时还会调整散射与厚度。参考 [fresnel.js](https://github.com/tapmaurer-repo/fresnel.js) 与 [Liquid Glass 的分层研究](https://github.com/sohumsuthar/liquid-glass)，本次把位移、柔化和反射分开处理，没有引入其 React 运行时或复制源码。

[Electron 的限制](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles) 仍适用：CSS 滤镜只能处理页面内可用的像素，不能独自模糊其他应用窗口。用户要求维持 Windows 透明效果关闭且岛出现在录屏中，因此沿用界外实时取样；本次的局部柔化只作用于已取得的边缘像素，不把它描述为整窗真实的 28px 桌面磨砂，也不声称完整物理 Snell 透镜。

## 修改

- 合并外轮廓为一条 1 CSS px、透明度 .36 的细线；删除四层 inset 阴影和两个额外伪元素描边。
- 上左与右下反射改为大范围柔光，峰值分别 .24 / .12。指针高光以 12 CSS px 连续向内衰减，取消硬边锥形环。
- 实时折射最高 alpha 改为 28%，整个环带连续向内淡出；渐隐宽度跟随厚度和 DPI，不再有不透明中间段。
- 沿深度连续遍历相邻的外侧纹理，避免把同一窄条向内拉成相框。所有双线性邻点仍验证位于真实轮廓外、距抗锯齿边界超过 1 个物理像素。
- 仅对折射 canvas 做 .8 CSS px 轻微模糊与 1.12 饱和度调整，柔化细纹，不模糊文本、数值、封面和交互控件。

保留清透主体、截图 / 录屏可见性、4Hz 局部内存采样及资源释放路径。没有静态壁纸贴图，也不创建额外可见检查窗口。

## 面板拖动与选择

用户追加要求：默认左键拖动面板内容即可移动窗口，不能在拖动过程中误选文字；选择文字应先悬停于文字，再水平拖动。

拖动与选择在独立 `ui/dashboard-drag.js/css` 中仲裁。非交互内容默认不参与原生文字选择；真实文字命中后悬停 320ms，再进行明显的水平拖动时使用 Range / Selection 选择，垂直或斜向拖动继续移动窗口。按钮、链接、表单、可编辑区域等绕过此仲裁，保留原有交互。窗口移动用开始位置加累计屏幕坐标差，合并高频消息；失焦、取消、隐藏和释放时结束手势。鼠标样式提示当前可选文字，快捷复制仍使用系统选择。

原生移动只接受监控面板自身发出的有限 IPC；灵动岛仍使用原有拖动模块。窗口失焦或大小变化会清理移动状态，位置限制保留可重新抓取的区域。诊断通过真实 DOM 手势与原生窗口位置验证快速拖动、悬停水平选择、竖向拖动和控件绕过。

同一对话的正文处于悬停选择意图或已有选区时，暂停该消息面板的 DOM 替换，避免实时日志刷新把 Range 删除。统计、快照和其他区域继续更新；选区释放后的下一次刷新使用最新快照，不回放积压消息。该判断也由手势模块的 `isReading(surface)` 统一提供，渲染器不重复识别私有手势状态。

## 验证

93 项单元检查通过。新增检查覆盖 100% / 150% / 200% DPI：环带没有不透明峰值，内沿从峰值单调淡出，所有取样点仍在安全域内；手势检查涵盖中文正反向选择、真实字形悬停、控件 / 触屏绕过、消息合并、资源释放与所属选区保护。

源码 Electron 检查通过，渲染错误为 0。复用同一个隐藏岛窗口，分别在浅色、深色与细纹合成背景下检查收起 / 展开、100% / 200% 缩放，共生成 24 张 0.3.5 与 0.3.6 对照图。旧环带峰值 255，新环带峰值 71；中心 alpha 均为 0。预览结束恢复尺寸、缩放、样式和交互状态，合成底图从 DOM 移除。诊断模块只在冒烟模式加载，正常运行不载入或执行。

示例位于 `artifacts/v0.3.6-source-final/`：`material-dark-compact-200pct-before-035.png` / `after-036.png` 可直接比较多重相框与新柔化边缘；`material-bright-expanded-100pct-before-035.png` / `after-036.png` 展示浅色背景下的变化。它们是明确标记的合成验收场景，不是产品使用的背景贴图。

最终成品 81 项检查全部通过，渲染错误为 0，包括原生窗口累计位移、悬停水平选择、垂直拖动、控件绕过及消息选区跨实时刷新保留。报告位于 `artifacts/v0.3.6-packaged/smoke-report.json`。`npm run release` 已打包替换，安装版 0.3.6.0，当前 PID 33292，启动错误日志为空。桌面快捷方式能恢复面板；正式便携包只保留 0.3.6 与 0.3.5。

安装后普通鼠标复查时 Computer Use 检测到用户正在操作窗口，已停止鼠标输入，没有继续争用光标；拖动的自动化验证依据是上述真实 DOM 手势与原生窗口坐标检查。
