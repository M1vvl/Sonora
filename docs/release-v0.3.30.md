# Sonara 0.3.30 逐项核对

## Q1 非网易云音源及音质

对照 MineRadio 源码检查 QQ、酷狗、汽水的官方取流请求及音质投影。使用 Sonara 自己的隔离加密会话副本进行只读验证，诊断仅输出状态、实际格式和有界字节数量。

- 酷狗返回的 Android CDN HTTP 地址此前被拒绝。现仅对准确的官方 CDN 升级 HTTPS，保留 Range 和签名查询。真实“Set for Life / Trent Dabbs”经受控流取得有效音频，隐藏播放器读取到 262.36 秒元数据。标准与无损请求在该样本均返回 128 kbps MP3。
- QQ 补充同曲媒体标识、AAC 候选和官方备用请求。真实同曲及另一歌曲样本的各请求仍返回文件错误码 104003，未取得播放地址，不能标为播放问题已全部解决。
- QQ 返回 104003 时，音质菜单不再展示无法使用的档位，并给出本次无授权播放地址的提示；其他网络错误仍照常上报。
- 对照 MineRadio 的官方 QQ 登录实现，扫码取得普通网页登录态后，在同一隔离会话内仅加载一次官方播放器页面，等待其写入播放专用凭证；二维码宿主和播放器辅助窗口在确认、取消或超时后都释放。已有播放凭证仍被官方接口以 104003 拒绝时，界面明确提示本次没有可用地址，不再把它误判为必须重新扫码。
- 汽水本机已保存会话经服务端核验已过期，需要用户重新扫码后才能验证该账号的真实取流。

播放器首次取流失败后仍可读取平台音质选项并重试。合法的汽水 `hi_res` 标识通过完整链路，音质标识长度统一为 40 字符。无音源时使用当前歌曲元数据，不沿用上一首音频对象的时长。

Spotify 的主播放器接入仍缺少本应用 Client ID 和 OAuth 回调配置。用户此前选择先完成其他平台，此项继续待配置。

## Q2 切换平台提示

移除“已切换到某音乐平台”的成功浮字。账号状态、连线及对应工作区照常更新。

## Q3 Spotify 登录面板

登录框按内容与浏览器区域收紧。Spotify 的 Google、Facebook、Apple 官方身份域使用精确允许列表，沙箱子页面保留 opener，关闭子页恢复父页面，唯一页面意外关闭仅恢复一次。

Google 官方禁止内嵌 WebView OAuth。宿主恢复修复不能保证 Google 接受内嵌授权，具体限制见 https://developers.googleblog.com/upcoming-security-changes-to-googles-oauth-20-authorization-endpoint-in-embedded-webviews/ 。Facebook、Apple 跳转完成代码验证，真实账号登录未进行交互验收。

## Q4 灵动岛旋转封面与默认页面

音乐页与 Agent 页共用碟片样式和旋转动画。紧凑页封面尺寸、位置一致，播放时旋转，暂停、页面不可见或用户关闭旋转时停止。启动默认进入音乐歌词页，左右滑动仍可切换 Agent 监控。

## Q5 外部进度与歌词

原生 UI Automation 回退扩展到 QQ、酷狗、汽水、Spotify、Apple Music 等进程，支持拆分的已播放时间与总时长。Apple Music 同时接入 Windows 系统媒体会话来源识别；这是外部播放器监测，不涉及 Apple 账号登录或 MusicKit。绑定过程验证所属进程和精确歌名、艺人，未知或过期时间不会作为真实进度显示。Apple Music 当前未运行，其真实歌曲进度与控制尚待运行时验证。

QQ、酷狗、汽水歌词优先在对应平台严格同曲匹配，失败后查网易云目录。短网络失败允许 30 秒后随已有媒体更新重试，空歌词缓存 5 分钟。修复来源切换后旧 pending 阻止重查的竞态。

本机网易云完全隐藏到托盘时，SMTC 只返回歌曲资料与封面，时间线为零。隐藏窗口 UIA 无时间控件，未发现公开本地播放状态 TCP 服务。因此该状态下真实秒数与逐句同步仍未解决。QQ 缺少当前运行样本，新增回退路径仅完成代码和解析检查。

## 验证范围

检查本轮修改过的音乐、登录宿主和灵动岛模块。针对性回归 382 项通过，包含 QQ 网页态到播放凭证的续接及受信任 HTTP 封面地址的 HTTPS 升级。原生编译、成品源码一致性、加密会话恢复及启动检查通过；音乐视图与真实账号交互验收由用户完成。
