## 回归修正

立体歌单的入场动画不再自动触发下一页预取，避免阻塞首个播放点击。靠近末端的实际导航才发分页请求，卡片节点继续保留。连续快速选择汽水歌曲会取消旧候选解析，旧请求无法占住最新歌曲的位置。退出网易云账号只影响网易云自身音频，酷狗数字歌单ID与歌曲hash分别校验。

QQ、酷狗、汽水的收藏修改和评论接口尚未迁入，界面不会把失败操作标为成功。会员音质遵从本账号官方响应。
