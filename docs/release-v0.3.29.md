# Sonara 0.3.29 音乐账号与推荐核对

## Q1 平台切换后的首页

- QQ 官方编辑推荐歌单、热歌精选、新歌首发、流行指数、飙升精选、网络热歌接入同一音乐工作区。入口封面取实际歌曲，点击读取对应平台歌曲并直接播放。
- 酷狗复用 MineRadio 的个人 FM 请求、现有签名和歌曲映射，接入官方热门歌单及其公开详情。公开歌单与个人云歌单使用不同标识。
- 汽水复用 MineRadio 原有推荐流与账号库降级路径。
- 首页与发现结果按平台过滤，同平台账号身份改变也会清空旧主页缓存。单一推荐端点失败时保留其他成功内容。

QQ 的榜单使用其真实名称。网易云的私人雷达等算法属于网易云，其他平台按实际可用接口显示入口。

## Q2 头像与平台资料

- 放行准确的 QQ 封面、QQ 头像和酷狗图片 CDN，官方 HTTP 图片安全升级到 HTTPS。
- QQ 使用服务端头像字段，QQ 登录缺少头像时使用官方 QQ 头像接口。微信登录的内部用户编号不作为 QQ 号码使用。
- 酷狗兼容头像 URL 编码，并只从匹配当前账号的创建者资料补充头像。
- 汽水兼容官方用户资料结构和多档头像字段，保留签名 URL。
- 账号头像、昵称、会员和推荐数据经过验证后更新对应平台。平台未返回头像时使用默认图标。

Spotify 仍缺少本应用 Client ID 与 OAuth 回调配置，网页登录不能提供本软件的账号资料、歌单和播放授权。用户此前选择先完成其他平台，该项保持待配置。

## Q3 登录后账号卡片

QQ、酷狗、汽水统一在验证成功后收起扫码、官方登录、验证和歌单按钮，显示头像、昵称、已连接状态及平台真实返回的会员信息。退出登录后恢复对应平台登录入口。

## 验证范围

运行账号卡片、平台工作区、推荐归一、图片域校验、账号隔离、队列与播放路由相关测试。QQ 官方公开接口在线检查包括 12 个带封面的编辑推荐歌单及五榜各 30 首歌曲。酷狗官方公开接口在线检查包括 18 个歌单和首个歌单的 21 首曲目。

真实酷狗、汽水账号和付费曲目的交互验收由用户完成。平台返回的会员、地区和版权限制继续生效。此轮增量替换当前安装。
