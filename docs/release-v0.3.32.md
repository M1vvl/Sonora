## Spotify 官方网页登录检测

增加官方网页会话的独立身份核验，只投影账号公开显示信息。官方播放器跳转或单页导航后进行最多三次延后检查，覆盖账号控件加载较晚的情况。核验成功后关闭登录网页并更新账号卡片。网页登录状态与 Sonara 主播放器的 OAuth 接入能力分别记录。

本机保存会话的隔离检查未取得可验证的 Spotify 账号状态，账号资料接口返回 HTTP 400。因此自动检测与收起已完成代码验证，真实账号成功登录后的交互仍待用户验收。

## QQ 推荐入口封面

新歌首发与流行指数可能收录同一首榜首歌曲。各入口现优先从各自榜单已载入的歌曲中选择尚未使用的真实专辑封面。选择顺序固定，播放顺序继续按原始榜单执行。没有额外封面可选时保留真实封面。
