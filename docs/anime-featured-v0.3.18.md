# 番剧主页高分横幅轮播（0.3.18）

## 用户需求与实现

原主页宽横幅外形、左侧热门/继续观看、下方四张卡片保持原布局。只在宽横幅内循环展示高分作品；`ui/anime/featured-rotation.js`负责随机集合、时序与生命周期，`ui/anime/index.js`负责真实目录适配和单个hero渲染。

- 使用当前热门目录实际评分≥7.5的作品，按ID去重，Fisher–Yates洗牌后选最多10部。已有主页候选不足时调用原`catalog`接口，按服务端游标最多补三页；仍不足则只用真实可用条目，不复制凑数。
- 每5秒切换下一部，当前集合循环；每5分钟重新取候选、随机选择。退出应用后不持久化此集合，下次启动重新选取。
- 只更新单个hero挂载节点，不重建下方四卡或观看历史。当前hero仍使用实际`data-item`编号，点击进入正确详情。
- 已选择的集合不改变分类标签、目录游标或播放历史。影视页继续使用原电影卡轨，完全不启用此轮播。
- 只有实际显示的番剧主页有一个单次计时器；隐藏文档、切出首页、停用或销毁均停止。5分钟期限在隐藏时到达，返回可见主页后再请求；不以后台轮询刷新。
- 隐藏/切页期间在途请求晚到会被代次检查丢弃，不再发后续目录页。下一个封面只作一张图片预读，停用清理引用；音频/视频不参与此模块。
- 轮换本身没有滑移或强制动效，减少动态效果偏好下仍按5秒换页，没有新增动画运行时。

## 验证

`tests/anime-featured-rotation.test.cjs`六项通过：真实分数/去重/不足不凑数、5秒与5分钟精确调度、隐藏/停用停止、迟到结果隔离、最多三页真实游标、隐藏中止后续页。

既有`tests/anime-ui.test.cjs`九项继续通过，包含原五张展示结构、详情交互、历史局部更新、目录分页与导航隔离。

`scripts/check-anime-featured.cjs`可传`--root`暂存app.asar及`--output`，使用全新隔离配置、匿名真实目录和隐藏Chromium。12项检查通过：真实目录有10部≥7.5作品、封面真实解码、宽横幅结构、10个唯一轮播项、5秒只换hero/不重建下四卡、隐藏停止、前台恢复一个timer、当前作品点击正确、停用/销毁释放、窗口保持隐藏、零renderer错误。报告与实际截图：`artifacts/v0.3.18-anime-featured/`。

测试只在隔离文档中应用正式保存的电光紫主题；不写入用户设置。5分钟随机刷新由受控时钟验证，不需要让应用隐藏空转五分钟。源站不足/失联时保留已有可用集合，下一次正常刷新再尝试，不伪造评分或作品。
