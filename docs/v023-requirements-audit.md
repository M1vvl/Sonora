## 需要保留的边界

- QQ 与 Apple 的官方网页登录入口已接入。账号个人歌单和音乐音源直接进入主播放器的适配仍待接通，接口明确返回 apiConnected=false。网页会话保存与账号验证状态分别展示。二维码由平台各自的官方流程生成。
- 权限绕过项按用户提供的跳过方案处理。七档是可请求的网易云档位，实际可用性与返回质量取决于账号和歌曲。
- 外部播放控制与时间来自播放器公开的 GSMTC 能力。外部歌词通过歌名、歌手、时长严格匹配网易云目录，匹配失败保留空歌词，避免显示错曲。本软件直接提供已取得的当前歌词。
- 操作系统向实体岛分发首个点击后，仍需接收后续点击才能识别双击。透明圆角外可穿透，实体区域的单击由岛接收。
- 自动审批审核拒绝删除旧头骨点云二进制和八张旧预设 PNG，未提供进一步原因。工作目录保留这些文件，构建配置与对应源码包已排除它们。旧功能的可执行代码已删除。
- Emily 的调度、资源释放、原源码调用和进度路径经过代码测试。真实设备的 GPU 流畅度、字体观感、颜色与登录页面仍由用户验收。

源码依据和功能接线记录分别见 `v023-music-providers-play.md` 与 Emily 适配清单。正式安装使用目录构建后增量替换，保持用户设置与播放元数据，便携包仅在用户要求发布时生成。
