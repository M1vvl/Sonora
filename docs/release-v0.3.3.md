# 0.3.3：同宽玻璃菜单、隐藏滚动条与 Harness 短状态

日期：2026-10-28。用户补充要求顶部只显示合适长度，保持原“助手”单行高度。

## 变更

- 删除会话栏下的模型 / 跟随模式副行；会话行高由 54px 减至 42px，原生展开窗口与页面同步由 272px 减至 260px。收起尺寸仍为 480×44。
- Chromium `appearance: base-select` 保留原生选择语义，在页面内显示可定制的菜单。使用命名锚点与视口硬上限限制菜单宽度，长选项不再撑宽；原生 `selectedcontent` 对关闭状态的长标签做单行省略。
- 选择器打开期间不重建选项，避免实时快照打断键盘或鼠标选择。菜单打开时不由岛的 Escape 处理器抢先收起整个窗口。
- 消息阅读区域使用 `scrollbar-width:none` 和隐藏的 WebKit 滚动条样式，仍为 `overflow-y:auto`，支持滚轮与键盘滚动，不显示右侧拖动条。
- 顶部角色名“助手”替换为实际日志活动摘要。工具调用、等待输入、完成状态或助手消息首句成为短摘要；不观察工具参数、不伪造进度、不输出隐藏推理。
- 独立单行显示模块保持 16px 高、13px 字号，最多 28 字符再由 CSS 省略。新旧状态以 240ms 同时向上退出 / 进入，高频更新最多保留一个最新待显示状态。切会话和隐藏时取消过渡，迟到的完成回调不能覆盖新会话。

本版沿用用户指定的清透降级材质，不修改 Windows 全局透明效果。菜单内部的 `backdrop-filter` 可柔化当前页面底层内容，但不宣称它单独提供跨桌面原生磨砂。

## 网上案例与选型

用户要求联网参考，本轮实际查阅了以下一手文档及演示：

- [Chrome：可定制 select](https://developer.chrome.com/blog/a-customizable-select)：`base-select` 将选项放在页面 top layer，可用锚点定位，并保留原有 JavaScript 值接口。本版保留浏览器原生的焦点与选择行为，没有手写缺少可访问性的列表菜单。
- [Motion：AnimatePresence](https://motion.dev/docs/react-animate-presence)：参考按稳定 key 区分内容、旧内容退出与新内容进入同时运行的 sync 模式；固定单行视口和绝对定位可避免排版跳动。
- [Build UI：Animated List](https://buildui.com/recipes/animated-list)：参考离开项与进入项的连贯视觉关系。其示例涉及列表布局，本版只保留单行平移，不引入列表高度动画。

这些是行为参考，未向小型桌面组件加入 React 或 Motion 运行时。现有 Web Animations API 只动画 `transform` 和 `opacity`，没有持续 RAF 循环；动效偏好复用 scroll / system / still 配置。

- 顶部状态在动画期间仍为 16px 高，两条文本同时向上衔接；切会话后旧动画已取消。
- 原有音频、封面、用量统计、透明通道、会话选择与岛收起检查继续通过。
