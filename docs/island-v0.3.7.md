# 0.3.7 灵动岛局部修复

## 律动条边缘

用户截图放大后，左侧第一条律动的两个端点有偏向左侧的一像素细小帽沿。原实现把有圆角的 18px 高矩形不断用 `scaleY()` 压缩，端点与圆角也一并压缩，可能落在非整数设备像素上。

保留原有三个频段、自动识别、能量输入和节奏平滑算法；显示模块改为三个绝对定位的小圆角条，设置真实高度，并把横向位置、宽度、上下端点对齐设备像素。圆角不再被比例压扁；条形局限在 `contain: layout paint` 的 20×30px 容器里，变化不影响周围布局。仅初始化和窗口尺寸变化时测量容器，帧更新不读布局；关闭页面时释放新增的尺寸监听。

此修复不通过遮盖桌面或关闭折射来掩盖细线，不修改系统透明设置，也不启用录屏排除。岛本身的轮廓高光仍保留。

## Token 右侧间隔

原头部左右均为 12px 内距。首先将胶囊靠近右侧；用户查看效果后追加要求“再往左移动一点点”。最终在上下约 4px 的基础上，向左回退 3px，右侧外间隙约 7px。用独立 `--metrics-end-adjust` 管理该微调，紧凑和展开沿用同一头部布局。原有字号、重点颜色和中心消息不变。

## 验证

- 音频及封面相关 12 项单元测试通过。
- 新增设备像素测试覆盖 100%、125%、150%、175%、200% 缩放和不同频段高度，验证四个端点均落在物理像素上，且页面退出释放监听。
- 新增 `src/diagnostics/island-chrome.cjs`，供成品冒烟在真实 DOM 上验证胶囊间隔和三条律动几何。最终成品检查由总发布流程执行。
