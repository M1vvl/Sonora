# Sonara 0.3.35

## Spotify 网页中转

登录 Spotify 后，在账号面板选择 Spotify 即自动启动专用真实浏览器中转。推荐、搜索、歌曲、账号歌单与收藏选择使用 Sonara 自有音乐界面，复用现有播放栏、歌单架与收藏面板。

专用 Edge 或 Chrome 负责官方网页播放，Sonara 对官网可见 DOM 执行固定操作并回读结果。此路径无需用户提供 Client ID。仅导入 Sonara 自有隔离分区内的 Spotify 登录 Cookie，浏览器使用独立配置目录与本机临时控制端口。

## 逐项核对

| 需求 | 实现与验证 |
| --- | --- |
| 登录后直接选择平台 | `selectProvider` 正常 IPC 自动启用中转，测试覆盖自有目录、搜索、收藏、播放及释放 |
| 推荐歌单与歌曲 | 真实账号读取 71–78 个官网歌单入口，首页使用官网实际返回的推荐与首个歌单歌曲 |
| 搜索 | 真实搜索 Night City 返回 14–16 首歌曲，直接映射到 Sonara 歌曲列表 |
| 账号歌单、收藏歌曲 | 读取官方音乐库，包含本账号“我的 #1 歌单”和“已点赞的歌曲”入口；支持空歌单 |
| 喜欢 | 通过官网歌曲菜单操作并回读实际状态；真实添加点赞与取消点赞通过 |
| 添加到歌单 | 列出官网实际提供的可写歌单，操作后等待指定目标的确认提示；真实添加成功并读取到歌曲，测试条目已删除恢复 |
| 播放、暂停、进度 | 真实 Edge 最小化后播放确认成功，进度推进与暂停通过；进度定位已回读核对 |
| 播放中浏览 | 使用官网自身搜索输入与页面导航；真实播放中搜索成功，歌曲继续播放且进度推进 |
| 重启信息 | 歌曲、队列与秒数沿用元数据存储，额外保存受限的官方页面路径，恢复时重新定位、校验歌曲并在线播放 |
| 关闭与退出 | 关闭主面板仍保留播放，完全退出释放本软件专用浏览器及连接；源代码核查覆盖生命周期 |

真实账号证据位于 `artifacts/spotify-browser-pilot/owned-session-result.json`、`feature-result.json`、`write-result.json` 与 `playback-result.json`。报告只含公开音乐与账号展示信息。

## 范围与限制

逐字歌词、网页音质调整、评论以及超长虚拟曲库的完整分页仍未接通。目录读取有数量和滚动次数上限。网站改版、登录过期或官方页面暂不可用时返回明确错误。

声音由真实浏览器播放。Sonara 不保存歌曲文件，浏览器仍使用临时媒体缓冲和有界静态资源缓存。首次连接需要加载官方页面，并额外占用浏览器进程资源。

本轮回归覆盖音乐改动及运行包一致性。音乐视图的最终观感由用户验收。采用当前安装的增量替换流程。
