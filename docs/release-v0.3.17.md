## 设计与资料

- [web.dev 浏览器级图片懒加载](https://web.dev/articles/browser-level-image-lazy-loading)：首屏可见图片直接加载，屏外图片延迟；高优先级不等于绕过懒加载。
- [MDN fetchPriority](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/fetchPriority)：有限关键图片可提示优先级，不应所有图片均设高。
- [MDN decode](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/decode)：解码完成后展示，减少空白切换。
- 动效沿用本地 Apple Design / Animate / Animation Performance 技能：手势反馈、空间连续性；不引入额外动画运行时。
