# 音乐五发现入口与完整卡片队列（0.3.18）

## 定向证据与范围

只读检查网易云安装目录 `D:/Music/CloudMusic` 的公开程序；程序为原生PE+NTPK包，没有可直接分析的JavaScript应用源码。REA `inspect cloudmusic.exe`返回 `provider_unavailable`（当前未配置Ghidra/IDA/Hopper等原生provider），所以没有声称还原出客户端或云端推荐算法。原始失败结果保存于 `artifacts/v0.3.18-discovery-rea/cloudmusic-inspect.json`。

继续使用可核验的本机MineRadio所带NeteaseCloudMusicApi原版模块：`personal_fm.js`、`playmode_intelligence_list.js`、`simi_song.js`、`user_playlist.js`、`recommend_resource.js`。REA精确选择5文件完成静态解析，证据在同目录`evidence`；源码路径与SHA256见`source-map.json`。另外人工核对MineRadio公开`03-home-discover-weather.js`和`04-home-empty-wallpaper.js`：它的“私人雷达”也存在使用当前推荐队列/首个推荐歌单的通用回退，不能把此行为当作网易云专属云端算法证据。

没有读取网易云/MineRadio账号、Cookie、音乐缓存或私人数据，没有代替用户写入收藏。

## 实现

`src/music/discovery.cjs`负责统一mode/provider分发和能力白名单，便于以后接入QQ/Apple Music。当前只有网易云实际接入；其他平台无适配器时返回未支持，不把网易云结果冒充其他平台算法。`catalog.cjs`保留实际官方协议与数据规范化，复用现有上下文取消、并发、歌曲目录和收藏状态；五发现入口列表每次最多30首元数据（完整金属卡deck有单独的全部雷达读取路径），不引入新播放器或音频缓存。

- 每日推荐：复用首页真实每日返回；匿名结果明确标记公开每日推荐，失败回退公开新歌推荐。
- 私人雷达：需登录，优先精确名含“私人雷达”的官方推荐歌单。未返回时手动入口可展示其他官方推荐歌单，并明确提示它不是专属私人雷达；合并卡片队列不采用这种替代歌单。
- 私人漫游：需登录，调用原版 `/api/v1/radio/get` 的FM队列。
- 心动模式：需登录，读取用户喜欢歌单，再调用 `/api/playmode/intelligence/list`。只读库和智能推荐，不代写收藏；缺少喜欢歌单/种子时明确返回，不能伪造个性结果。
- 相似歌曲：需要当前合法歌曲ID，调用 `/api/v1/discovery/simiSong`，过滤种子本身；无结果如实提示。

登录服务和既有桥暴露 `discovery {mode,seedId?,source?}`，只返回规范化歌曲/歌单和准确label/message。权限、取消、服务失败不暴露Cookie或原始错误配置。

## 卡片完整队列

最新追加覆盖之前“三张/五张循环”的逻辑：界面可同时显示五层，但循环队列不是五首。`home.cards`首先提供完整有序、去重的每日推荐（最多30首），不再洗牌或仅随机取五首。

随后前端可后台请求`deck`，在原每日顺序之后追加精确私人雷达歌单原始顺序，跨两部分去重。私人雷达通过完整trackIds顺序补齐缺失歌曲，每批最多30首，仅在所有ID均已返回时更新；雷达上限500首、加每日最多530首；整轮结束再回每日第一首。只缓存有界元数据，不下载音乐。未登录只有准确标记的公开每日队列；登录后未找到精确私人雷达或读取失败，保留完整每日队列并说明原因，不把普通推荐冒充雷达。

首页和deck的短期memo包含北京时间日期键，跨日后下一次请求更新；切页或重启允许重新读取。没有持续后台轮询。前端负责在用户已经滑动时保留当前ID和相对顺序，不因迟到合并响应重置其正在操作的卡片。

## 验证

34项音乐内容/发现/播放选项相关单元通过，包括：五mode能力分发、非法源拒绝、登录前拒绝私人请求、正确FM/智能/相似协议、喜欢歌单只读、取消与迟到结果、30首上限、完整daily→radar顺序去重、北京时间跨日刷新、无雷达时准确提示。

2026-10-30真实匿名官方请求7项检查全部通过：公开每日30首、卡片30首完整同序、匿名deck只保留每日且radarCount=0、相似歌曲5首；三种私人模式在本应用未登录时正确要求登录。报告`artifacts/v0.3.18-discovery-rea/anonymous-live.json`。没有使用本人登录测试私人接口或会员权限，相关行为依赖本人授权账号与服务端实际结果。


完整雷达补充验证：95首雷达（首30首tracks+95个trackIds）分30/30/5批补齐，源服务即使倒序返回详情也按原trackIds组装；70首完整tracks无需额外详情请求；超过500首或trackIds/歌曲缺失时明确返回radarError与提示、保留每日队列，不把前30首冒充完整雷达。此路径不修改常规30首列表、不下载音频或封面。
