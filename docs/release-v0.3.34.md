# Sonara 0.3.34

- 删除沉浸歌词全屏左上角的“退出全屏（Esc）”节点、点击绑定和专用样式。保留捕获阶段 Esc 回退以及播放栏全屏按钮；验证退出全屏后歌词页继续显示。
- 修复 Spotify 平台路由：只有真正取得音乐 API 授权且返回账号资料时，才使用 Sonara 原生音乐目录；网页登录状态继续与 API 授权分开，不能伪报曲库/音频接通。显示账号资料时优先采用当前真正授权账号，避免不同会话资料混用。

Spotify 用户要求的完整原生界面与本地播放器接入尚未完成。既有 Web Playback SDK 路径需要 Spotify 应用注册、用户授权、Premium 和可用 DRM 播放环境；现有官网网页登录不会自动产生 Sonara 的应用授权。此次没有借用其他应用的授权或绕过 DRM，也没有把网页视图包装当作完整接入。用户已明确选择保留账号并暂缓 Spotify 接入，后续等待用户重新提出接入要求。

相关 51 项回归检查通过，账号资料优先级修改后额外复测账号测试通过。本轮只检查音乐相关改动，不对番剧/影视重复验收。
