# 0.3.1 发布记录

2026-10-28，已完成便携打包、稳定安装替换与启动。安装版本 0.3.1，Electron 成品检查 33/33 通过、渲染错误为 0；相关 Node 检查共 43 项通过。

## 本版功能

- 后台音乐播放器公开系统封面时，Agent 图标切换为当前歌曲封面。使用 GSMTC 媒体属性和播放状态事件，随曲目变更更新，不从历史播放记录猜测当前曲目。
- 网易云的 SMTC 经用户明确授权开启，实测读到多首歌曲的不同标题与真实封面。图片在内存中转换为 96×96 PNG，仅变化时发送；异步旧图片不能覆盖新歌。
- 播放时旋转、暂停停转；无识别会话、播放器退出、封面无效时恢复原 Agent 图标。可选择旋转、跟随系统或静止，不修改 Windows 全局动态设置。
- 展开区已删除置顶 / 隐藏按钮，会话选择栏填满该行并调整高度；置顶与显示开关仍可在主面板设置中操作。

QQ 音乐等播放器需要发布系统媒体信息；当前未逐个启动实测。Mineradio 本机版本的系统封面发布尚未确认。REA 证据与静态分析边界见 [music-cover-rea.md](music-cover-rea.md)。

## 发布及保留

用户要求后续版本都完成打包替换，仅保留最新版与其前一个版本。本次已保留 `Agent-Pulse-0.3.1-Windows.exe` 和 `Agent-Pulse-0.3.0-Windows.exe`，删除 0.1.0、0.2.0、0.2.1、0.2.2、0.2.3 的便携 EXE。

统一命令为 `npm run release`：暂存构建、原生组件检查、成品检查，随后备份并替换稳定安装文件、启动核对版本，最后清理更早的便携包与临时安装备份。Windows 上目录句柄可能阻止整个安装目录重命名，因此安装文件复制在程序停止期间完成，失败可从备份恢复。稳定快捷方式目标不变。发布清单位于 `release/release-manifest.json`。

未清理用户数据目录、Token 索引、配置、项目源码或 REA 分析记录。
