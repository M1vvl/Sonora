# 音乐歌单抽屉与播放队列

本轮通过现有音乐 provider 与单一 audio 播放器适配 MineRadio 的交互思路，未复制其界面运行时，也未读取 MineRadio/网易云的账号凭证。协议来源和主进程鉴权核对由对应的音乐后端记录说明。

## 模块

- `ui/music/library.js/css`：左侧边界悬停显示玻璃歌单抽屉。触屏/键盘可点击边界入口；鼠标离开后单次 180ms 隐藏，重新进入取消隐藏。登录面板、离页、关闭或销毁时释放定时器、图片观察和监听。
- `ui/music/queue.js`：纯队列规则，最多1000条去重元数据。顺序、单曲循环、随机播放共用实际歌曲列表；随机采用不重复袋，上一首返回真实播放历史。单曲循环只影响自然结束，手动上一首/下一首仍切歌。
- `ui/music/player.js`：只增加队列控制，继续复用唯一 `<audio>`。同排按钮顺序为播放模式、上一首、播放/暂停、下一首、当前队列；收藏到歌单在爱心旁。移除当前歌曲会切换到下一条并保留原暂停意图，清空停止音频并解除地址。

## 数据与操作

抽屉首次打开才请求本账号歌单，按30条分页；选择歌单后按30首分页，显示实际总量并提供加载更多。尚未全部载入时按钮明确标注“播放已载入歌曲”，不把首批30首冒充完整歌单。账号切换/退出登录会清除旧列表和迟到响应。

“收藏到歌单”只展示本人拥有的目标，只有用户点击目标后才发送 `playlistAdd`。后端仍以真实账号和新鲜歌单详情独立验证所有权，不信任前端 owned 标记。收藏失败仅显示短暂提示，不假装成功。

当前队列支持直接点播、移除和清空；列表仅在歌曲/队列实际变化时更新，不随音频时间刷新整张列表。无新轮询、音频缓存或第二播放器。

- 图像 `music-library-playlist.png` 与 `music-workspace-1536.png` 是合成图案封面的诊断画面，不是本人音乐库截图。
