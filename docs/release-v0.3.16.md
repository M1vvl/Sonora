## 模块职责

`src/music` 负责公开协议、加密账号、目录和偏好/历史；`src/music-bridge.cjs` 仅组装可信 IPC，`music-images.cjs` / `music-stream.cjs` 分别控制图片队列和单一当前歌曲的音频流。`ui/music` 分别负责账号浮层、页面工作区、单一 audio 播放器与金属卡片。实时监控与灵动岛不接收音乐完整目录，不增加监控轮询。
