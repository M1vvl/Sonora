## 来源核验与 Error

Kazumi `lib/services/plugin/rule_engine.dart` 在 API/XPath 分集解析后拒绝空 roads。本应用保留既有规则引擎模板，新增 `source-discovery.cjs` 组合搜索与该分集检查：只有实际解析出至少一集的候选才进入可选列表。每源具体条目检索最多核对前 12 个，广泛名称会提示缩小范围；沿用最多三个来源 worker、四个网络请求的限流。成功分集缓存最多 120 项、合计 20,000 集，十分钟 TTL，规则变化及取消具有请求代次隔离。

`artifacts/kazumi-rea/v0.3.9/source-validation.json` 实际验证 DM84 返回《学生会也有洞！》12 集。其他来源当次连接失败不算成功；空列表、验证页面或接口故障不会伪装成可播放来源。非空分集只能证明该规则解析到剧集地址，第三方媒体仍可能随后失效。

主页 Error 涉及取消时复用被中断的同键 Promise，以及底层取消原因只有通用 Error。目录取消现在分离在途代次、保留成功缓存；网络区分 AbortError、超时、连接失败和真实 HTTP 状态。界面忽略已经离开页面的旧取消，其他错误转换为有上下文的中文说明，新路由成功后清除旧提示。

## 播放器几何与自动隐藏

普通窗口旧宿主减去 72px 右导航和 16px 顶部，播放只占剩余区域；现改为完整 client area，返回移除播放视图即可恢复原页面，不重建详情。底部由原集数/暂停附加行缩减为 72px 控制区，顶部为 50px；两者隐藏后视频占整个窗口或全屏。

隐藏逻辑独立于帧状态：2.5 秒静止、150ms 移出，菜单/拖动持有命名保持项；暂停不会持续唤醒控制栏。原生指针使用物理像素、DOM 使用 CSS 像素，明确的 changed 布尔值优先，避免高 DPI 坐标误判。滑出动效 160ms 后由单次可取消计时器释放布局，不依赖隐藏视图中可能停滞的 CSS 事件或动画帧。视口继续用 RAF 合并加 50ms 一次性兜底，没有新增持续布局轮询。

保存视频截图的 DOM、前端分发、主进程处理、对话框及正常原生命令均删除。诊断帧捕获需要显式的 diagnostic 构造参数及 helper 启动标记，产品启动不具备该能力。此内部接口用于检查 GPU 实际输出，不是保留隐藏的用户截图功能。
