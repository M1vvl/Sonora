1. QQ、酷狗、汽水、Spotify、Apple Music的真实登录与跨平台音源切换：用户已确定首期只接网易云，其他保留入口；当前仍属预留。

3. 封面永远秒开、第三方视频源永久稳定/零卡顿、保证原生4K：无法由本地播放器保证。当前是有界重试/多源隔离/缓存等实际改进，失败仍会如实返回。
4. 系统透明关闭时的全表面Apple原生磨砂：当前按已选择清透降级处理。已有局部边缘折射不等于整个桌面背景的透镜取样。
5. Claude与其他播放器/其他机器所有路径：模拟或本机部分验证不等于每个产品/环境都已实测。

上述均已在产品标注或文档中区分；本轮要求范围内未发现需要继续修改的阻断缺陷。最新发布记录原先遗漏更新的“待验收”字样和旧测试数字现已补齐。旧版本文档作为历史记录保留，不作为当前未完成项重复执行。
