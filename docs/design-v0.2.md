## 事件计费

读取日志明确提供的请求用量，输入包含缓存、输出包含推理。用量事件展示实际 Token 与按模型估算的金额。纯工具调用与没有用量字段的助手消息显示“未单独记录”，不为了模仿截图填入虚构的 0 Token / $0。

请求级 token 与可见文本消息不一定一一对应，因此单独保留“模型用量”卡片；不会把相邻请求金额强行归给一段助手文字。汇总对多个日志里的同一请求去重。

## 完整历史与每日

数据范围是本机实际存在并能读取的会话日志，包括归档。被删除、云端且未同步到本机的历史无法恢复。历史金额按日志中的模型计价；无官方已核对价格时保留 Token、显示未定价。

每日边界固定为北京时间（UTC+8），同时支持历史合计、今日与具体日期。首次扫描渐进展示进度；扫描完成前不标为完整。解析失败或文件读取失败显示数据状态。

本地账本用于跳过已处理的文件前缀，日志追加后只解析增量；文件截短或重写时重新索引该文件。缓存仅保存统计所需字段与有限长、隐藏常见凭据的预览，不保存登录凭证或原始工具参数。

## 项目导航

只读 Codex 本地项目名称、根目录和显式对话归属。优先使用显式项目关联，其次按最长匹配目录归组；没有匹配的会话保留可见。空项目也保留。子代理默认折叠，不改变总用量计算。

## 玻璃与交互

Windows 11 22H2 以上使用 Electron 的系统背景材质 Acrylic；其他情况提供 CSS 透明样式回退。窗口外围按胶囊 / 面板圆角裁切，避免原生背景露出矩形边角。背景透明度单独控制，不对整个窗口降低透明度。

灵动岛尺寸保持收起 500×76、展开 540×280，点击立即响应、手柄拖动跟随指针。数字不作跳动动画；状态只作轻微透明度提示。降低动态效果、降低透明度和高对比偏好都有对应样式。
