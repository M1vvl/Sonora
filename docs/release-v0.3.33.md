# Sonara 0.3.33 · Spotify 官方网页工作区

本轮仅修改 Spotify 音乐工作区、账号展示及其生命周期；使用当前安装的增量更新，不新增便携安装包或版本归档。

| 用户问题 | 实现与核查 |
| --- | --- |
| 登录后不能切换音乐界面 | 已验证的 Spotify 网页账号可保存为当前音乐平台，重新启动可恢复选择；不要求应用 Client ID。 |
| 没有推荐、歌单和收藏 | Spotify 工作区直接承载同一登录会话的官方页面，提供推荐、我的歌单、收藏歌曲、搜索导航；不混用网易云目录或伪造歌单。 |
| 只要一种播放方式 | 账号卡片只保留官方播放器入口，移除授权增强/客户端设置入口。实际受保护音乐通过“在浏览器中播放”打开系统浏览器；保留官方页面已选择的歌单/专辑路径。 |
| 昵称显示长 ID、无头像 | 官方公开账号资料与可见账号组件合并；不再用不透明 ID 作昵称。实际头像可用时显示，未取得头像时显示昵称首字母。 |
| 弹窗、切换和关闭可能冲突 | 官方原生视图在账号弹窗/沉浸界面中隐藏，切换其他平台或关闭主面板时释放；所有绑定和延后验证均有停止路径。调整尺寸不会重置官方页面。 |

真实账号只读核查：使用当前已安装 Sonara 的 Spotify 自有会话，确认登录状态、昵称 `kietl`、官方页面中 113 个歌单链接。官方返回资料与当前可读页面未提供可用头像，已提供首字母回退。该核查没有读取密码、输出 Cookie 或播放令牌，没有操作用户歌单。

运行时边界：当前 Electron 45.1.0 对 Widevine EME 的实际请求返回不支持。系统浏览器播放与 Sonara 内嵌网页是独立浏览器会话，首次打开系统浏览器可能需要在 Spotify 官网再登录一次。该模式不需要开发者 ID，但不声称 Sonara 自有音频播放器已能直接解码 Spotify 受保护音频。歌曲的实际播放、收藏写入与个性化推荐由 Spotify 官方网页处理，尚未对真实账号进行可见交互验收。

检查证据保存在 `artifacts/v0.3.33-runtime/`。本轮音乐/媒体相关回归共 437 项，其中一项原生媒体映射子进程在并行运行时达到 5 秒超时，独立复测通过，其余 436 项通过。安装源码一致性 156 项、隔离账号重启检查与启动 25 项检查已通过；运行中的安装版本为 0.3.33，app.asar 与准备安装的版本哈希一致，诊断端口已关闭。不重复检查番剧和影视功能。
