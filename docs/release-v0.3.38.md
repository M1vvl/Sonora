# Sonara 0.3.38 逐项核对

本轮仅核对设置、音乐和相关材质代码；番剧、影视不复验。音乐视觉验收由用户完成，不将代码测试称为像素一致性验收。

| 需求 | 实现与验证 |
| --- | --- |
| Q1 拟态玻璃开启时播放栏出现矩形底色 | 移除全局面板材质对沉浸播放栏定位容器的覆盖，保持播放栏自身的圆角、阴影、透明度，与拟态开关解耦。 |
| Q2 精简设置页 | 删除顶部标题、副标题和“已保存”，移除本地连接及 Token 价表的呈现、DOM 更新、事件；音乐律动补入桌面体验旁的网格。保存与错误提示功能保留。 |
| Q3 Emily 对照原源复原 | 保留原源 4.8 平面、183² 点网格与着色器。恢复边缘开关、染色与背景适配参数、中心正方形采样、256/384/512px 纹理、520ms 换封面及180ms景深过渡。共享 FFT 对齐原源2048点/.58平滑，并修正低频取样边界；移除父层额外节拍注入，保留原源节拍/强度算法。来源路径与上游SHA256见 source-manifest.json。 |
| Q4 歌单完整播放 | 主页、侧栏、立体歌单共用完整分页读取，在线队列最多10000首元数据；页面分批100行呈现，保存仍1000首/512KiB，不缓存歌曲。取消/坏游标/超限明确反馈，拒绝半份歌单冒充完整。Spotify 虚拟列表须实际滚到稳定底部，未到底提示失败；已测51/1201首分页与620首Spotify模拟目录。 |
| Q5 纯主题歌词模式 | DIY 常用新增“纯主题 · 歌词”，与 Emily 模式分别可选并持久化；保持歌词、翻译、播放栏，隐藏封面粒子，以当前主题作舞台底色。原视觉开关仍独立工作。 |

账号保护沿用当前 Windows 用户独立的系统加密/浏览器受保护会话存储，不将凭据打进 EXE 或源码。运行时只保存队列、进度等元数据，不缓存歌曲文件。
