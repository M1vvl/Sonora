# 0.3.22 发布前需求校对

## 本轮五组问题

| 需求 | 代码校对结果 |
| --- | --- |
| 单按钮顺序/单曲/随机/列表循环、单曲回环图标、删除重复模式按钮 | 已接入真实队列逻辑和持久化；原播放器节点复用；模式循环与自然队尾行为有回归测试 |
| 禁止音乐展示区选字/复制、删除底栏重复视觉设置 | 已接入独立交互策略和样式，保留搜索等真实输入框编辑；仅保留 DIY 视觉控制入口 |
| 歌词/背景分离、独立有界缩放、自动更新、喜欢/加入歌单 | 独立前景 Scene/Camera、单 renderer，分别缩放；真实播放时间与共享频谱驱动。修复收藏面板鼠标穿透及提示层级，平台操作要求明确回执 |
| 首次进入/切换空白、沉浸音域回响缺失、卡顿 | 标准预设复用上下文，跨源等待真实绘制再替换；快速连续切换/失败保留最后有效画面。修复嵌套 CSP/ESM 和暂停启动；暂停不再隐藏原生歌词。减少重建和有界资源属于代码优化，未进行实际帧时间或视觉性能验收 |
| 常用预设与歌词按音乐律动 | 源主循环真实频带、峰值归一化与攻击/释放映射至原 shader/歌词。虚空按原作无粒子，不伪造节拍；减少动态效果仍保留 10fps 语义更新 |

216 项音乐单元/集成测试与 14 项原生歌词 CPU 合同通过。成品校验另记录于 `artifacts/v0.3.22-packaged/`；这些不是 GPU 像素、真实账号收藏写入或用户视图验收。未做鼠标操作，未复查番剧、影视、监控视图。

## 历史需求尚未完成的边界

不能将以上五组修复等同于全部历史需求已完成，尤其不能宣称整个 MineRadio 的六页签已完整 1:1：

- 完整登录/本人歌单/播放目前为网易云；Apple Music、QQ、酷狗、汽水、Spotify 尚未接通，沿用用户此前允许“遇阻先跳过并报告”的范围。见 `v021-platform-integration.md`。
- 立体歌单/详情是 CSS perspective 的适配，不是原版完整 Three.js 歌单与镜头跟随/遮挡系统。
- 独立桌面歌词、自定义歌词与字体上传、完整多命名视觉存档、部分玻璃/独立控件配色、全局快捷键、摄像头手势等未完整迁移。
- 系统级修改页/待机页清理和管理员提权未实现；现有功能只回收本软件工作集，不冒充全局清理。
- 整曲 beatmap、外部 DJ 分析和原版完整 cinema/自由镜头控制台未迁移；已接入的真实短窗频谱不代表这些功能完成。
- 原版场景与歌词核心文件保留原 SHA，宿主仍有缩放/设置映射、平台和生命周期适配；像素观感及真实歌曲连贯性由用户后续验收。

详细证据：`release-v0.3.22.md`、`music-v022-playback-audit.md`、`v022-source-space.md`、`v0.3.22-workshop-audit.md`、`assets/music/source-presets/lyrics-source/INTEGRATION.md`。
