# 0.3.5：边缘实时折射、右侧竖轨和七套主题

## 确认过的技术边界

Apple 的 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 将背景折射、边缘透镜和随交互变化的高光作为材质特征。[Electron 官方文档](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles) 说明，CSS 滤镜只能处理窗口内部，不能直接模糊窗外其他应用；SVG 位移也需要可用的背景像素作为输入。只加一条渐变边框不能称为真实桌面折射。

公开的 [HostBackdropBrush](https://learn.microsoft.com/en-us/uwp/api/windows.ui.composition.compositor.createhostbackdropbrush?view=winrt-26100) 不提供背景像素读回，效果也受系统设置约束。[Win2D 位移效果](https://microsoft.github.io/Win2D/WinUI3/html/T_Microsoft_Graphics_Canvas_Effects_DisplacementMapEffect.htm) 标为 NoComposition，不能简单接到该背景画刷上。

另一个通用办法是排除自身窗口后采集背景，但 [WDA_EXCLUDEFROMCAPTURE](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity) 会同时让岛不出现在系统截图和录屏里。用户明确要求保留录屏可见性，因此本版**不调用内容保护或截图排除 API**。

## 保留截图可见性的边缘方案

本版只对岛的内侧约 6px 环带进行真实像素位移，中心仍直接透明。使用 [GetDC / BitBlt](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-bitblt) 取得岛附近的小块实时画面，沿圆角矩形外法线，从轮廓外邻近背景取色，再折回内侧边缘。不是静态壁纸、缓存贴图、随机图案或对文字做扭曲。

为避免自反馈，映射表构建时逐一验证每个双线性采样的四个邻点都在岛轮廓外，且离边界大于 1 个物理像素。测试还把岛内部和抗锯齿边缘的全部源像素改成另一种颜色，逐字节确认输出不变。透明圆角之外的像素不会含有岛内容；原生窗口无外阴影，避免把阴影采入。因不需要排除自身窗口，岛仍可出现在截图和录屏中。

这是面向边缘的折射近似：背景在环带里弯曲，中央不做透镜放大，不宣称完整复刻 Apple 的专有材质或物理光线追踪。额外的矢量亮边和按指针位置变化的高光用于表达厚度，光效与真实背景采样明确分开。

局部 DIB 仅在内存中创建，不编码原始画面、不保存或上传。采样最多每秒 4 帧；几何映射按尺寸缓存，移动只更新坐标。使用物理像素转换处理 DPI 和负屏幕坐标。隐藏、关闭功能、销毁窗口或退出应用会停定时器并释放 DC / Bitmap；失败时降级为边缘光效，不影响 Token、音乐和封面。GDI 无 HDR 色彩管理，HDR 显示的颜色准确性不作承诺。

Electron 的 [V8 内存笼](https://www.electronjs.org/blog/v8-memory-cage) 不允许把外部 DIB 内存包装成 ArrayBuffer。因此原生层保留不透明指针，经 `RtlMoveMemory` 复制到普通 Buffer，避免外部视图导致进程退出。成品冒烟中会建立 8×8 内存 DIB，以合成字节模式完成原生读写回环；该检查不读取桌面。

实现按职责分为 `src/refraction.cjs`（原生资源与生命周期）、`src/refraction-map.cjs`（有界几何和取样）、`ui/liquid-edge.js/css`（独立小帧和高光）。不新增后台程序、不做全屏采集，也不触发完整历史广播。不修改 Windows 全局透明效果。

## 监控面板

完全删除左侧品牌与状态栏，释放内容宽度。右侧为通高亮色圆角竖轨，保留总览和设置的图标与可访问名称，当前项使用深色圆角底。最小化和最大化按钮已删除；底部出口按钮采用 24×24 网格的门框与右箭头，路径上下关于 y=12 对称，统一线宽与端点，不拼接字体。它关闭面板并保留托盘监控。

用户随后要求隐藏竖轨左侧的主内容滚动条。本版在 `.content-scroll` 隐藏可视滚动条，继续使用 `overflow-y:auto`，保留滚轮、触控板与键盘滚动；项目列表、消息列表的独立阅读区域不受影响。

主题按参考图顺序提供，每张图是一套完整组合，保存到 `interfaceTheme`；切换只改变界面，不重启监控或重新索引。原图部分色名、RGB 与 HEX 有冲突时，以 HEX 为准。正文使用有色深底和冷白；竖轨和金额卡使用大块对比色。三色主题的第三色真实出现在金额卡中，并非仅保存在缩略图色板里。文字在各自底色上分别校验对比度。
