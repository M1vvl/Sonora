## 需求与实际作用

| 需求 | 实现及作用位置 |
| --- | --- |
| 点击歌词，从下向上覆盖整个 UI | `immersive.js/css` 的 body 层 fixed 全屏面板；覆盖右侧竖轨，原面板 inert；返回小房子和 Esc 从相同路径退出。进入/退出动画允许中断，不创建新窗口。 |
| 复用播放栏与账号 | 将同一播放器、账号胶囊和歌单架 DOM 临时移入二级页面；返回恢复占位节点。全程只有一个真实 audio，播放进度不因切页重置。 |
| 队列右侧 DIY 与右下设置 | DIY 只在二级页当前队列右侧出现；开启后显示右下控制钮，再打开设置。离开恢复原播放栏，不遗留 DIY。 |
| 无歌词留白、歌词居中、当前行上抬 | `lyrics.js/css` 去标题和空状态文字；歌词及平台译文居中，当前行有轻微上抬。二级页使用同一已读取歌词，不重新拉取副本。 |
| 九种预设 | 单 Canvas 提供封面、安境、音域地形、音域回响、星河、唱片、星球、滚筒和虚空九种实际绘制方式。高分辨率封面作圆形/球面明暗，地形与波纹取实际频谱，装饰粒子漂移与真实音频强度分开。虚空不绘制粒子/频谱。 |
| 背景与媒体 | 歌曲封面、自选图片/静音视频、纯色；透明度、模糊、裁切左右/上下、缩放直接作用于背景媒体 DOM。自选媒体使用用户选中文件的临时 Blob URL，不复制文件；关闭二级页后撤销 URL，重新打开需重新选择。 |
| 配色、玻璃 | 视觉主色默认跟随当前主题，DIY 自选只作用于本面板；歌词颜色、播放栏玻璃厚度即时应用，不改全局主题或正式 `settings.json`。 |
| 歌词显示与翻译 | 关闭/单行/双行/三行/多行/沉浸；多行数量、译文当前/双行/多行、间距/字号/透明度，真实改变当前歌词 DOM。平台未提供译文时留空，不生成虚假译文。 |
| 字体与动画 | 系统/衬线/圆润/等宽、字号、字重、水平/垂直位置、角度、光晕、当前行上抬开关，均应用于歌词样式。 |
| 律动、镜头 | 强度、景深、128/256/384px 封面请求、指针镜头和幅度；粒子开关/数量/尺寸/速度；实际频谱开关/高度；音域方块开关/数量。指针镜头是页面指针景深，不访问摄像头。 |
| 歌单架 | 关闭/侧栏/舞台、移开自动隐藏/常驻、展开动画、宽度/圆角/透明度；使用已有同一个账号歌单模块，不再请求另一份数据。 |
| 系统、存档 | 15–30fps 上限；搜索设置、单项重置、全部重置、撤销、最近 20 次修改历史、JSON 导入导出。标量参数经白名单和界限校验后保存到独立 `music-visuals.json`，最大读取 16KiB。不包含音频、账号或媒体文件。 |

## 明确的条件与未接通能力

- Wallpaper Engine 需要独立原生桥接，本版不携带该桥，因此界面明确禁用并说明条件；普通图片/视频背景和独立音域回响预设可用，不冒充 WE 集成。
- 独立桌面悬浮歌词需要另一个窗口，与当前软件内二级页职责不同，本版保留软件内歌词并提示条件。
- 不访问摄像头、麦克风或桌面，不实现参考图中的摄像头/手势采集；“指针镜头”仅使用鼠标坐标。
- 系统未安装的字体使用系统字体回退；上游无译文/封面时保持真实缺失状态。自选媒体只在当次二级页内保留，标量设置则退出重开保留。

## 资源与验证

`visual-renderer.js` 只有一个最高 960×540 的 2D Canvas、一个与现有 audio 绑定并跨打开复用的 AudioContext 和 512 点 Analyser。可见且播放时才请求帧，暂停/隐藏/退出/减少动态效果停止帧；系统减少动态效果只停视觉，不暂停正在播放的音频 Context。关闭二级页保持同一播放链，完全销毁时才断开并关闭。音量、静音仍由真实 audio 元素控制，没有增加会重复衰减音量的 GainNode。频谱平滑残留不代表音频仍在输出，诊断同时测量实际时域 RMS。

- `tests/music-visual-settings.test.cjs`：2 项白名单、数值界限、独立存储重启通过。
- `scripts/check-music-immersive.cjs --root <源码或app.asar> --output <目录>`：30 项隐藏原生 Chromium 检查通过，包含全 UI 覆盖、同一播放器和账号搬移、九预设实际 Canvas 像素各不相同、字号和单行真实应用/保存、非零真实音频分析、音量 0/静音时域 RMS 为 0、取消静音恢复、减少动态效果时 Context 仍 running、再次打开不重复创建播放器/DIY、返回音频时间继续增长、暂停和销毁释放。
- `scripts/check-music.cjs`：105 项生产 dashboard/preload 检查通过，新增从真实音乐主页面打开沉浸页、DIY 和返回恢复的三项；原登录、抽屉、队列、收藏到歌单、三种宽度排版等检查保留。
- 上述测试只使用隔离配置、合成账号和 RAM 生成的短测试音，不使用真实凭证，不写入真实歌单，不操控用户桌面鼠标。图像和报告在 `artifacts/hotfix-music-immersive` 与 `hotfix-music-immersive-full-shell`。
