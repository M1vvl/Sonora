# Codex 可见会话统计范围修复

本次直接修改当前版本源码，不改版本号、不生成便携压缩包。`src/codex-scope.cjs`独立负责只读的桌面项目、归档状态和子代理归属；`monitor.cjs`在去重、费用、累计、每日和热图数据汇总前统一筛选。

## 纳入规则

- 优先使用最新`state_N.sqlite`中真实的`projects`和`project_roots`，兼容旧桌面全局项目数据以及迁移后的项目 ID。数据库项目列表为空时不恢复旧全局项目。
- 纳入显示项目中的未归档主对话，以及它们正常`thread_spawn`子代理的完整后代。子代理继承主对话所属项目，包括不同工作树的子代理，避免生成额外的目录项目。
- 排除归档主对话及其后代、归档目录副本、guardian、无可见父对话的孤立内部代理，以及桌面已明确移出项目或设为无项目的对话。
- 已有桌面索引时，未入索引的旧日志不作为历史复活。真实显示目录中的新活动日志保留两分钟索引延迟窗口；持续写入会延长窗口。
- 兼容没有桌面元数据的 CLI 安装：按已有配置目录推断项目，仍排除归档。Claude 的原有日志解析和目录分组保持原行为。

旧缓存必须先经过同一筛选才能产生快照；重新发现会移除被排除的缓存状态。归档父对话即使原日志已经缺失，仍能依靠只读索引排除后代及其继承基线。仅项目或归档元数据变化也会发出更新，无需等待新 Token。

此范围下“历史完整”指现存合资格日志已从头读取；不代表已经补回云端未同步或本地已删除的日志。缺失日志数量继续在诊断字段中报告。
