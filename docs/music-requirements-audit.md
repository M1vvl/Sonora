## 本轮审查发现并交回修复

1. 正常页面一次加载超过四张封面时，第五张曾被图片协议直接拒绝。已改为最多4个活跃请求、64个排队请求；24张封面批量、队列取消和退出释放回归通过。
2. 原生弹层退出动画结束前恢复背景焦点，真实 Chromium 可能拒绝该焦点；UI 负责方已将恢复移动至原生关闭之后，并补充动画中停用页面的关闭处理。
3. 最近播放每十秒更新曾重建全部推荐列表和封面；UI 负责方已拆出仅更新最近播放的渲染路径，隐藏页不重绘列表。
4. 最近播放此前仅保存秒数而未恢复；UI 已增加元数据就绪后的续播定位，并隔离切歌后的迟到元数据。
5. 公开新歌回退曾仍显示“每日推荐”；后端与 UI 已增加准确来源标签。
6. 收藏返回值不明确时曾可能更新爱心；UI 已要求官方成功后返回确切布尔状态。
7. 卡片高度曾形成 ResizeObserver 反馈循环；挂载区固定负责高度，观察器只合并通知、在帧/50ms 单次兜底中测量，已验证没有渲染器错误。

8. 真实网易云 CDN 部分图片使用 `image/jpg` 别名；原 MIME 白名单拒绝了已成功下载的封面。已规范为 `image/jpeg`，补充缓存回归，并通过真实封面与 GPU 链路验证。

## 卡片独立验证结果

最终复核命令：

```powershell
D:/Tool/node.exe --test tests/music-cards.test.cjs
D:/Tool/node.exe scripts/check-music-cards.cjs --output artifacts/v0.3.16-cards-final-audit
```

10 项单元检查和 21 项隐藏 Electron 实际 GPU 检查通过。报告 `artifacts/v0.3.16-cards-final-audit/music-cards-report.json` 没有材质或渲染器错误。

- 实际画布 256×256，上限 384×384；封面纹理上限 512×512，环境两次模糊的缓冲为 256×256。
- 倾斜后的边缘平均 RGB 差为 10.22，清晰中心为 2.15，说明变化主要集中于倒角反射，而不是把封面整体模糊。
- 静止不继续上传或调度帧；隐藏、停用和销毁释放 GPU、图片引用及待处理帧。
- 960/1260 宽度下，三张卡片右上边缘保持递进，无裁剪，主题保持 `electric-purple`。

这些结果验证了资源上限和行为，不等同于承诺任意显卡上固定帧率或整款软件内存下降某一百分比。UI、官方匿名接口、实际受控封面/音频流和打包检查由各自报告补充。

## 仍需区分的限制

实际本人账号的扫码确认及对本人歌单的收藏操作由用户完成，测试没有替用户授权。歌曲可播放性受官方账号权限、地区与版权限制，不绕过权限或将试听片段伪装为完整歌曲。其他四个平台目前是入口预留，符合用户指定的首期范围。
