## 实际模块边界

- `src/music/netease.cjs` 的歌词方法改用官方客户端所用 `/api/song/lyric/v1` 请求字段，允许平台返回 YRC；没有因此增加整曲音频下载。
- `src/music/lyrics.cjs` 负责有界 YRC/LRC 解析、逐词时间与字符范围、译文对应。真实逐词数据标为 `yrc-word`，只有逐行数据时标为 `lrc-line`。YRC 保留文字内的普通括号，拒绝过大的时间戳，最多 1,200 行、12,000 词。
- `ui/music/lyric-motion.js` 是小歌词卡与二级歌词页共用的投影。每个投影只保留附近最多 17 个行节点；换句保留仍在窗口内的原节点，整首歌词仅保存有界元数据。当前句跟随音频 `currentTime`，有 YRC 时逐词填色并保留实际词间间隙；LRC 使用当前行至下一行的平滑进度，不宣称它等于真实逐词演唱时间。
- `ui/music/lyrics.js` 负责歌曲和请求生命周期、分享同一数据给多个 `createView()`；`lyric-motion.css` 负责居中、渐变、羽化和上下文外观。沿用现有播放器，没有新增 audio 或独立音频图。
- 二级页由 `immersive.js` 调用 `lyrics.createView(target,{immersive:true,getSettings})`，并在显示、隐藏、设置变化、销毁时调用相应投影接口。

## 已接通控制

| 控制组 | 实际作用 |
|---|---|
| 关闭、单行、双行、三行、多行、沉浸、行数 | 控制可见行窗口，偶数行数也严格保持指定数量；边界不额外多显示一行。 |
| 译文显示、间距、字号、透明度 | 译文来自平台已有文本，开关与范围在现有节点上生效，不生成伪翻译。 |
| 字体、字号、字重、行距、字距、上下文间距 | 父级字体配合文本测量重排；同一句改变字号/间距也立即更新定位，不必等下一句。 |
| 上下文透明度、边缘渐隐 | 当前行与上下文分离，显示窗口的上下边缘使用透明遮罩。 |
| 填色、羽化、填色响应、运动柔和度 | 控制当前行填色的边界和时间插值；响应与柔和度都真实参与计算。 |
| 扫光、微光、光晕与音频联动 | 作用于当前句的亮度/滤镜/光晕，能量取同一共享分析图的短窗数据。 |
| 平稳、浮动、故障；故障强度/切片/色散/频率/抖动 | 实际改变当前句的变换与色散；平稳和系统减少动态效果关闭跳动/振荡。 |
| 三维景深、深度、位置、倾斜、文字颜色 | 由二级页的既有舞台容器/CSS 三维投影应用，不混入歌词请求或音频解析。 |

## 生命周期与验证

暂停、结束、遮挡、隐藏或停用时取消歌词动画帧；未显示的投影只存时间/歌词元数据，不测量文字、不建立行节点。页面恢复后从当前媒体秒数同步。切换/清除歌曲会先清旧词，迟到请求不能覆盖新歌；停用整个音乐模块会停止其所有歌词投影。销毁移除媒体监听、观察器、节点及分析图租约，最后的共享图关闭仍归原歌词材质创建者负责。
