# 0.3.13 面板状态恢复

本修改合并在 0.3.14 交付，未单独替换用户运行版本。

修复“项目与对话”窗口关闭、完全退出重开后恢复默认状态的问题。主题、玻璃材质与统计口径不变。

## 范围

- 独立保存当前导航、选中会话、项目与子代理的展开状态、搜索与 Agent 筛选、统计范围/固定日期、明细展开、Token 活动模式及相关滚动位置。
- `%APPDATA%/Agent Pulse/dashboard-state.json` 仅保存上述 UI 状态，不保存日志正文、Token 副本或主题。白名单、集合/文件容量约束、原子替换，相同状态不重复写盘。
- 操作合并 180ms 保存，关闭窗口前补齐未提交状态。初始索引期间等待目标会话；不存在的会话在索引完成后回退。
- 搜索临时展开不覆盖原折叠偏好；延迟原生 toggle、热图首次布局、隐藏页面及用户主动滚动均有对应处理。无持续轮询。
- 源码修改与验证直接进行；完成全部改动后统一生成并替换一次运行版本，无需每个小修改重打完整包。已安装 Electron 程序仍需更新程序文件并重启才能应用。

## 内存实测

修改前 0.3.12、2026-10-29 亚洲/上海，当前运行实例的 6 个进程（主进程、GPU、网络、一个渲染器、音频与媒体 helper），无视频 helper。4 次样本私有驻留工作集平均 303.14 MiB、范围 258.46–325.79 MiB，占系统可见 15.74 GiB 物理内存的 1.88%。

相加的普通工作集平均 642.19 MiB 会重复包含共享页；私有提交 425.89 MiB 不代表全部驻留物理内存。此数据是采样场景，并非包含视频播放等所有功能的峰值。原始证据：`artifacts/v0.3.12-memory/current-memory.json`。
