# 0.3.22 音乐修复核对

本轮仅检查音乐功能代码。按用户要求，不进行音乐视图、GPU 像素验收，也不复查监控、番剧、影视和视频播放器。未修改用户主题、系统透明效果或正式账号。

| 用户需求 | 修复与核查 |
| --- | --- |
| 直接点击切换播放模式、单曲自循环图标、补齐列表循环 | 顺序→单曲循环→随机→列表循环，单一按钮与图标同步；顺序队尾停止、列表队尾返回首曲，保存模式；移除菜单与沉浸界面的重复随机按钮 |
| 禁止音乐展示文本选择/复制，删除重复视觉设置 | 独立 interaction-policy 限制音乐呈现区选区与全选/复制；真实输入框可编辑。移除底栏视觉设置按钮，仅保留 DIY 入口 |
| 歌词与视觉独立、分别缩放 | 复用同一 WebGL renderer，分离前后景 Scene/Camera、清除深度后绘制歌词。visualScale 与 lyricScale 独立保存，均限 0.55–1.65；原装歌词字体仍有自己的最终尺寸限制 |
| 不操作鼠标也更新歌词、场景与浮空粒子 | 播放时由真实 audio.currentTime 与共享 analyser 驱动；减少动态效果时保留 10fps 语义更新，弱化运动；暂停、隐藏和关闭停止调度，不以随机信号代替音乐 |
| 喜欢与添加到歌单可用 | 复用原播放器节点与账号 API；修复立体歌单样式误用到收藏面板的鼠标穿透，等待平台明确确认，提示跟随当前页面。测试不修改正式账号收藏 |
| 进入/切换空白、卡顿、沉浸音域回响不显示 | 标准预设间复用 iframe/context；跨渲染器保留旧画面，首次真实绘制才提交新画面，最多两个宿主。修复 Workshop 嵌套 CSP、ESM 请求和暂停冷启动；失败及连续快速切换保留最后有效画面；暂停不再隐藏已绘制歌词 |
| 所有常用视觉与歌词按音乐响应 | 接入原主循环频带 RMS、峰值归一化、攻击/释放和预设差异增益；沿用原 shader、歌词推进与律动。虚空按原作保留无粒子行为 |

源代码证据和边界见 `music-v022-playback-audit.md`、`v022-source-space.md`、`v0.3.22-workshop-audit.md`。原装 7 份场景依赖和 11 份歌词模块保持原 SHA；宿主通过独立适配文件接入，没有复制第二个 audio 元素、额外音频文件或整个音乐运行时。

代码验证：`node --test tests/music-*.test.cjs` 216 项通过；`node scripts/check-source-lyrics-contract.cjs` 14 项通过。覆盖四种模式、原节点传送后的点击、收藏确认、源模块哈希、歌词几何/逐字 shader、分离空间、无鼠标时钟、低动效调度、首次绘制握手、协议限制与资源释放。这些结果不等于实际 GPU 视觉或正式平台写入的验收。

发布使用 `scripts/release.ps1 -MusicCodeOnly`，打包后再比对音乐源码与成品、验证隔离进程账号恢复；只替换当前安装，保留当前和前一版便携包，不增加历史源码归档。
