# 0.3.25需求核对

2026-11-06。核对范围仅包含本次音乐、灵动岛和设置改动，番剧、影视及播放器集成由用户验收。

| 编号 | 请求 | 实现与边界 |
|---|---|---|
| Q1 | 关闭面板后继续播放音乐 | 当前音频流或未完成取流存在时，关闭改为隐藏原窗口。音乐、队列和下一首沿用原audio。隐藏清理账号浮层、歌单、封面、歌词视觉及动画，保留播放请求。无音乐时关闭释放面板，完全退出仍停止音乐。后台续播保留原renderer，因此会有必要的进程占用 |
| Q2 | 网易云有歌却不能播放 | 修复单次高档请求失败即拒绝的问题，加入有界逐档、旧接口和严格同名/艺人/时长站内恢复。旧接口缺少单曲code时不再误判，明确拒绝码和试听仍拒绝。真实匿名条目已返回完整音源，用户截图未包含具体曲名，特定账号的歌曲仍待用户验证 |
| Q3 | 高清臻音可用 | 修正高清臻音为jyeffect、全景为vivid，匹配原协议客户端及编码字段。旧偏好迁移，实际Hi-Res响应独立显示。降档明确显示实际音质并短暂提示。会员和曲目未授予此音质时仍返回可用档位，不能把HQ称为臻音 |
| Q4 | 设置右侧拟态玻璃和透明度 | 主题标题右侧放开关及设置按钮，原生窗口逐像素透明，应用与主题表面分责，关闭恢复原实色主题。透明度只调整表面，文字不跟着变淡。原生使用文档化DWM接口，无截图、桌面贴图或额外常驻采样。当前Windows全局透明效果关闭，因此真实运行只能清透降级，无法声称桌面磨砂已实现或视觉通过 |
| Q5 | 显示灵动岛开关左侧透明度 | 增加独立按钮，使用共享透明度对话框，分别保存islandOpacity和dashboardOpacity。同步修复灵动岛明暗自适应分支忽略原透明度参数的问题 |
| Q6 | 新主题及橙色替换 | 新增克莱因蓝#002FA7/松花黄#FFE76F及马尔斯绿#01847F/玫瑰粉#F9D2E4完整双色方案。原ember-orange保留ID兼容，改爱马仕橙#FF770F/深蓝#000026。绿粉主题内容区使用深绿基底，导航为粉，重点卡使用原马尔斯绿，保证小文字对比度。正式配置读取到霓虹脉冲neon-pop，本轮不替用户切换 |
| Q7 | 移除Apple Music | 移除账号行、官方URL/域名、登录脚本特殊分支、源选择、MusicKit错误分支及原生Apple专属识别。五行登录面板自然收紧。保留通用GSMTC能力和HLS标准application/vnd.apple.mpegurl MIME，它们属于其他通用功能 |

## 模块与资源

`dashboard-lifecycle.cjs`管理关闭与隐藏，`dashboard-material.cjs`管理原生DWM，`ui/dashboard-material.js/css`负责设置、表面材质及共享透明度对话框。网易云恢复逻辑位于独立`netease-playback.cjs`，Qishui的QR关闭与API取消分责，避免隐藏面板取消准备中的歌曲。

`settings.json`保存玻璃开关及透明度，旧配置缺少开关时默认关闭。主题选择保持用户保存值。Qishui账号安全验证与音乐API独立，关闭登录浮层仅释放QR资源，退出登录才取消账号API。

## 验证边界

音乐和设置代码测试、源码合同、原生编译及安装后哈希检查写入本轮报告。匿名真实网络验证不下载音频。尝试独立配置读取本应用已保存的加密账号，在safeStorage解密阶段失败，未发送真实账号请求、未写正式资料。用户个人歌曲及会员臻音未标为实际通过，视图由用户验收。
