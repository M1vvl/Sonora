# Sonara 0.3.27逐项核对

2026-11-06。本轮范围为窗口轮廓、启动显示、拟态材质、歌词层次及更名和图标迁移。视觉由用户验收。

## Q1圆角外残线

原生窗口原本同时使用24DIP GDI区域和系统DWM圆角，系统边线可能沿较小圆角呈现。现使用DWMWA_BORDER_COLOR与DWMWA_COLOR_NONE抑制系统边线，并让单一GDI区域约束圆角与四角命中区域。保留厚边框对应的边缘缩放能力。显示、恢复和激活时合并重新应用区域，避免几何缓存跳过被系统覆盖后的恢复。[Microsoft边框属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)

浏览器根画布统一透明，只有裁切后的app-shell绘制背景。轮廓改由shell内部的伪元素绘制，移除原body固定轮廓，避免方形画布与圆角表面的残留叠加。

13项形状回归通过。实际隐藏原生窗口核对了角点排除、中心保留、区域重建及厚边框保留，报告位于`artifacts/v027-native-frame.json`。API接受结果与视觉验收分别记录。

## Q2偶发空壳窗口

主窗口原先只使用首次ready-to-show设置永久就绪标记，重载和renderer退出时没有撤销，也没有主面板恢复路径。恢复视图时同步构建失败会留下已被选中但未构建完成的容器。

新增独立就绪控制器。本地文档加载完成、实际renderer恢复工作区并发出握手后才显示，显示前请求重绘。隐藏透明窗口的ready-to-show仅作诊断，不作为必需门槛。所有监听在loadFile前完成注册，主frame导航或renderer退出会撤销旧状态。初始化超时、加载失败与renderer退出复用现有恢复模块，60秒最多两次，关闭后释放监听和计时器。

视图构建失败回到可见总览，异步目录与快照请求不阻塞界面就绪。工作区读取失败时暂停默认状态落盘，保留旧文件。正常隐藏和重显保持同一个renderer与音乐拥有者，仅请求重绘。

真实隔离Electron检查曾复现已加载并完成握手但ready-to-show持续不触发，促使移除该事件硬门槛。修正后21项集成检查通过，包含实际HTML/preload、故障注入后的单次恢复、状态读取失败回退、隐藏重显无重载。全程窗口未显示，合成IPC，零远程请求，报告位于`artifacts/v027-dashboard-startup/startup-report.json`。这是生命周期验证，用户设备的所有偶发GPU触发条件尚未逐一重现。

## Q3拟态玻璃立体边缘

拟态模式采用窄内倒角，顶部和左侧高光、右侧反光及底缘阴影表达厚度。边缘层全部位于同一圆角区域内部，pointer-events为none。深度层使用静态内阴影，没有额外全窗口模糊循环。原主题和保存不透明度继续生效。

用户保持Windows透明效果关闭，本轮继续采用雾面降级表面。桌面真实模糊仍受该系统设置限制。

## Sonara名称与最新橙色图标

软件用户文案、主窗口、托盘、灵动岛等待标识、程序元数据与启动入口统一为Sonara。稳定程序位于`release/win-unpacked/Sonara.exe`，项目启动脚本为`启动 Sonara.vbs`。

更名后沿用`%APPDATA%/Agent Pulse`及原应用标识，以延续已有加密账号、主题、队列和播放记录。自启使用原内部Run值名，只更新属于本安装的旧程序路径，保留Windows已记录的禁用状态。精确指向旧稳定程序的快捷方式迁移到新入口，图标指向Sonara.exe。安装事务失败可恢复原程序与入口，旧历史版本资料按现有规则保留。

图标采用用户最后提供的橙色原图，完整复制到`assets/icon.png`，SHA256为`0d741a3a15d73618a99d7424ba6cf5b695db50ef0043630ab95a317f2f1677d5`。Windows ICO由electron-builder的图标工具按原比例转换，包含16至256px七种尺寸。主窗口和托盘使用相同图片，快捷方式使用主程序内嵌图标。
