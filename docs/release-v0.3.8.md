## 实现边界

播放器使用主窗口中的隔离 WebContentsView，右侧导航仍可用。视频原生子窗口只占视频区域，菜单与画面调整面板会收缩该区域。解析第三方页面的隐藏沙箱只负责识别媒体地址，没有监控日志权限。Windows 全局透明效果与灵动岛设置不变。

## 原生与视觉验证

- 134 项单元检查通过，包含原规则、设置、控件、宿主、协议和既有用量回归。
- 独立隐藏静音实例的 13 项集成检查通过：只有原主窗口、视频有效区域、真实视频、沙箱、进度/暂停/倍速、画面调整、原页面返回、历史保存、两档着色器执行、有效截图尺寸、处理后像素差异、组件释放。
- RTX 4060 Laptop GPU 上实测 libmpv `gpu-next`、D3D11 与 `d3d11va`。这是本机场景证据，不推导其他显卡性能。
- 对同一实际视频帧缩小到 320px 后固定输入，使用原生 `screenshot-to-file ... window` 取得处理后的 1208×678 画面。关闭、效率档、质量档像素摘要不同，并从 `vo-passes` 确认真实 CNN Upscale pass；仅有 `glsl-shaders` 配置值不能替代此证据。
- 初期隐藏视图没有调度动画帧，导致 HWND 保持 1×1。修复为 RAF 合并加一次性 50ms 兜底，测试覆盖帧停滞与销毁取消。最终验证不使用 1×1 截图，不把 API 成功当作完整画面。

## 档位与模块

效率档七段、质量档六段，顺序完全沿用 Kazumi；九个 GLSL 保留原许可证并逐字节核对。自动、裁切填充、拉伸填充和 4:3 来自原实现，16:9 是本应用增加的选项。倍速范围沿用 0.25–3，每档 0.25。关闭模式清空全部外部着色器，不采用 CSS 锐化冒充超分。

状态帧独立发送，只有换集或设置变化才发送完整播放状态；设置、宿主、解析器、Windows helper 和控件分别管理。返回前保存真实进度，旧代次设置/截图不覆盖新播放。原程序、账号和系统设置不被修改。

证据路径：`artifacts/v0.3.8-player/player-report.json`、`off.png`、`efficiency.png`、`quality.png`；构建成品还将重复同一检查。
