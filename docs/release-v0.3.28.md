# Sonara 0.3.28 逐项核对

2026-11-06。范围仅为本轮修改的音乐、账号工作区、启动与窗口表面；番剧、影视和视频播放器没有重新验收。音乐视觉交由用户验收，不操作真实桌面进行目测。

## 外边缘与拟态开关

- GDI 圆角区域使用包含最后物理像素的右/下边界。浏览器画布透明，只有单一 app-shell 表面绘制主题，向内留出 1.25 CSS px 抗锯齿余量，避免圆角像素被原生区域硬裁切。
- 默认表面没有边缘伪元素和阴影；仅 `data-dashboard-glass=true` 时增加窄内倒角、高光、侧缘反光和底部厚度。保留保存的主题及透明度，未修改 Windows 全局透明设置。
- 隐藏、合成画布检查覆盖 96/120/144/192 DPI 与拟态开关共八种组合，修复后的非透明像素被原生区域裁切数量均为零。旧区域对照能检出问题。报告：`artifacts/dashboard-edge-report.json`。这不是对真实桌面的视觉验收。
- 启动仍以本地文档和 renderer 初始化握手作为显示条件。默认音乐页的隔离 Electron 检查包含隐藏重显、audio 保留、故障恢复和重新握手，报告：`artifacts/v028-dashboard-startup-fixed/startup-report.json`。

- `assets/icon.png` 为本轮最终附件的完整原图，SHA256：`505eb7b67813b21c6cd153a6471e37752f867cc2d6a6f25a41e4f518595742dc`。ICO 由构建工具按原比例生成，包含 16/32/48/256 px 等 Windows 尺寸。
- 沿用原应用标识及 `%APPDATA%/Agent Pulse`，避免改名造成账号与偏好重新初始化。

## 网易云 Night City 取流

已复现歌曲 ID 1806096519 在当前账号取得完整授权的 192 kHz/24 bit FLAC，但 Chromium 无法解码。流头包含 418,677 字节内嵌封面元数据。正常化后该曲通过真实播放以及 10/100/180 秒拖动续播；另一个 96 kHz 样本亦通过。报告：`artifacts/netease-diagnostic.json`。

独立 `flac-stream.cjs` 仅处理网易云 FLAC：有界读取流头、保留 STREAMINFO 和相对音频偏移的 SEEKTABLE，移除不影响音频的可选元数据，再映射虚拟 Range 到原始音频帧。没有重编码、整曲内存缓存或音频落盘。上游遵循背压，停止时取消；错误流头、长度和并发均有上限。

这修复了已复现的解码类别，不代表所有版权、区域限制或平台故障都可绕过。音质显示仍取官方返回的实际档位，不把请求档位当作实际已取得的音质。

## 面板内扫码与真实平台工作区

- QQ 与酷狗在独立、沙箱化、不可见的官方页面生成二维码，仅把二维码图片传给本地账号卡片。禁止新窗口、Node 和非白名单导航。刷新、取消、三分钟过期、关闭面板和退出均释放宿主；服务端 profile 验证成功后才报告账号连接。
- 实际网络核对已取得 QQ 111×111、酷狗 387×387 的官方二维码，取消后挑战失效。报告：`artifacts/v028-qr-live.json`。未代替用户扫码，不声称用户确认后的账号/付费歌曲链路已经实测通过。QQ 二维码明确标为 QQ App 扫码，不伪称 QQ、微信、QQ 音乐可共用一个二维码。
- 独立 `provider-workspace.cjs` 管理活动平台。切换成功后胶囊、主页歌单、搜索、歌单详情及后续播放转到该平台；未开放的推荐算法入口隐藏，不偷偷展示网易云数据。来源本身仍受对应账号授权及平台可用性限制。
- 活动平台存入现有偏好状态仓库。快速切换时旧结果失效、异步保存串行化；取消、失败和退出不会把磁盘偏好留在被淘汰的平台。过期账号保留平台选择并明确未连接，不自动回退至网易云。浏览平台选择与当前 audio 拥有者独立，不中断当前歌曲。
- QQ、酷狗、汽水的播放和音质沿用各自现有 provider 适配；未开放的收藏等操作明确报不可用，不冒充成功。Spotify 主播放器仍缺少本应用 OAuth 配置；Apple Music 已按用户前轮要求移除。

## 验证与替换

对应单元检查、成品来源/语法一致性、隔离账号重启与启动检查通过后，使用 `scripts/update-runtime.ps1` 事务式增量替换稳定运行目录 `release/win-unpacked`，安装记录在 `release/runtime-update.json`。不生成新的便携 EXE 或历史源码留存包；随程序提供许可证要求的 corresponding-source.zip。

替换前正式配置：klein-yellow、拟态关闭、表面不透明度 0.9、Windows 透明效果 0。发布后再次核对这些值。用户数据、音乐账号和播放元数据不作为清理对象。
