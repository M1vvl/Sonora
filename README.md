# Sonara

[下载 Windows 单文件版](https://github.com/M1vvl/Sonora/releases/latest) · [直接下载 0.3.41 EXE](https://github.com/M1vvl/Sonora/releases/download/v0.3.41/Sonara-0.3.41-Windows.exe)

打开发布页，在 Assets 中下载 Sonara 对应版本的 Windows.exe，保存到自己的文件夹后双击运行。运行依赖由程序自动展开，首次启动会有短暂等待。各用户的账号保存在自己的私人数据目录。

仓库 Code 页面提供开发源码，可直接运行的软件在 Releases。“启动 Sonara.vbs”用于启动已经在源码目录构建好的程序。

## 直接运行

双击 `release/win-unpacked/Sonara.exe`，或项目目录的 `启动 Sonara.vbs`。这是便携程序，无需安装、不需要管理员权限。灵动岛默认显示在主屏幕顶部，双击胶囊展开或收起，拖动左侧手柄移动。展开后可选择对话，置顶、显示和自动隐藏开关位于主面板设置中。

主面板按“项目 → 对话”组织，读取 Codex 的项目名称和对话归属。子代理默认折叠，普通分叉对话保持可见。可搜索、筛选 Agent、切换完整历史 / 每日日期、查看历史与当日双汇总、查看近期活动及 JSON 导出。事件使用独立机器人 / 齿轮图标，Token 和美元金额以较大高亮标签显示在右上角。

关闭面板时，存在播放或待完成取流会保留音乐拥有者并隐藏窗口；空闲时释放面板，监控与灵动岛保留在系统托盘；彻底退出请右键托盘图标选择“退出 Sonara”。单击托盘图标即可打开监控面板；再次启动桌面快捷方式也会打开面板。右键托盘可开关灵动岛、重置位置。设置默认关闭开机启动。窗口紧贴胶囊，收起 480×44、展开 520×260，禁用标准厚边框和外阴影。展开后可选择各项目对话或自动跟随当前活动，Esc 收起；菜单打开时先由原生选择器处理 Esc。灵动岛显示当前对话的用量；每日 / 完整历史的切换统计在主面板中。

软件只读 Windows「透明效果」偏好；关闭时使用逐像素清透窗口，真实透出壁纸与下层窗口，不启用会退为实色的系统材质，也不会修改 Windows 设置。玻璃主体使用逐像素透明、矢量图标和亮边，不使用静态壁纸贴图或全屏采集。0.3.5 起另有局部实时边缘折射：只使用轮廓外侧邻近像素，中心仍透明，不等于全表面磨砂或透镜。系统允许透明时保留独立原生 Acrylic 路径；该路径尚未在本机开启透明效果的条件下完成视觉验收，不承诺 Apple Liquid Glass 的实时折射。

## 自动音频律动（0.3.0）

灵动岛左侧三条默认自动响应正在播放的声音，无需手动选择播放器。通过 Windows WASAPI 共享输出回环识别默认输出设备上的活跃音频会话，分析 45–250Hz、250–2000Hz、2000–10000Hz 的频谱能量；快速响应、缓慢回落，不使用随机动画。默认输出设备改变后自动重新连接。网易云已在本机实测；QQ 音乐、Mineradio 等使用相同系统通道，未逐个启动测试。

这是频带能量律动，不是精确 BPM/节拍转录。多个声音会混合影响显示，非默认设备、独占/受保护音频可能无法响应。不开麦克风、不保存或上传音频。设置提供“关闭律动”和“仅常见音乐播放器”，正常使用无需更改；后者只限制启动识别来源，不隔离输出混音。

音频模块独立于 Token 监控。隐藏灵动岛、关闭律动或退出应用会释放音频 helper；静音时条形回落，无音频会话时降低检查频率。系统启用“减少动态效果”时以最多每秒 10 次的离散数值反馈显示条形，不做平滑动画。主面板只在需要时创建，音乐帧使用独立小 IPC 消息，灵动岛不接收完整历史。

## 计价

界面只显示 Token 对应的美元估算，不显示订阅费。计算式为：

```
美元 = ((输入 − 缓存输入) × 输入单价 + 缓存输入 × 缓存单价 + 输出 × 输出单价) / 1,000,000
```

输入已包含缓存，输出已包含推理，二者都不会重复计费。价格按日志中的实际模型匹配 OpenAI 官方 Standard 文本 Token 单价，核对日期为 2026-10-28。未知模型显示“未定价”，部分可定价的汇总显示已知下限。

这项统计是 API 单价的参考估值，不是实际扣费账单。日志未提供可靠的处理档位和完整附加费信息，因此不含 Fast / Ultrafast、长上下文加价、图片、语音和托管工具费用。Plus 剩余额度如在本地日志可见，可单独显示真实窗口观测值及观测时间；不会把 token 数换算成订阅剩余额度。

官方来源：

- [OpenAI API Pricing](https://developers.openai.com/api/docs/pricing)
- [Codex 计费说明](https://learn.chatgpt.com/docs/pricing)

已核对的价格保存在 `config/pricing.json`。调整开发版价格后重启；便携成品使用打包时的价格表。没有默认套用 Terse 的通用单价。

## 数据与范围

- Codex：默认 `%USERPROFILE%\.codex`，支持 `CODEX_HOME`；只读会话索引和 `sessions` / `archived_sessions` 的 JSONL。
- Claude Code：默认 `%USERPROFILE%\.claude\projects`，支持 `CLAUDE_CONFIG_DIR`。
- 默认完整扫描本地普通与归档日志，不限日期、文件数量和初读大小；历史索引缓存到用户数据目录的 `history-cache.json`，之后每 1.5 秒增量读取。首次扫描展示进度，完成后再标记索引完成。每日以北京时间划分，支持具体日期选择。
- “完整”指本机现存且可读取的日志。已经删除、云端未同步的历史不能恢复；读写异常或解析异常会明确提示。活动列表只保留最近 100 条预览，历史 Token 统计不受预览数量限制。
- 支持新版 `token_usage_record`、旧版累计 `token_count`、模型切换、缓存输入、推理输出、半行追加和常见重复记录。
- 新旧累计计数分别维护基线，避免旧日志累计与新版请求用量重复；子代理重放的父会话元数据不会覆盖自身身份。归档副本、缓存重启和日志追加均做去重。
- 进程发现只读取 Codex / Claude 进程名与 PID（兼容回退模式可返回可执行文件路径）。活动状态来自日志，长时间没有更新会标为空闲；不是推理过程的连续探针。
- 目前这台机器已验证 Codex。Claude 解析通过本地模拟日志测试；尚未发现真实 Claude Code 会话。其他 Agent 需增加对应日志适配器，当前不宣称已支持。
- 不读取登录凭证，不发送会话到远程，不使用外部 CDN。消息预览有限长且对常见凭据形式做隐藏，工具仅显示名称；导出仍可能包含项目路径与消息预览。

界面配置保存在 `%APPDATA%\Agent Pulse\settings.json`（更名后沿用原数据目录，以保留已登录账号和偏好），不会修改 Codex、Claude 或 Terse 的配置。

## 开发与验证

需要 Node.js 和 npm：

```
npm install
npm run build:audio
npm run build:media
npm start
npm test
npm run smoke
npm run pack
npm run dist
npm run release
```

`npm run smoke` 使用独立临时配置启动真实 Electron 窗口与只读本机扫描，检查桥接隔离并在 `artifacts` 写入截图和报告。`pack` 输出可直接运行的文件夹，`dist` 生成单文件便携 EXE。首次安装需下载 Electron；若 npm 的脚本策略阻止下载，可运行 `node node_modules/electron/install.js`。

`build:audio` 使用 Windows 随附的 .NET Framework 4.x C# 编译器构建 x64 音频 helper 并运行内存中的 FFT 自检，无额外 SDK。`node scripts/audio-diagnostics.cjs` 是约 4 秒的本机输出诊断，仅保存数值摘要。打包时将小型 helper 放入 `resources/native/audio`；诊断证据和 Mineradio 资源不进入成品。

每次版本更新完成后统一执行 `npm run release`，自动暂存构建、检查成品、替换运行目录并启动新版，然后只保留最新和前一个版本的便携 EXE。`dist` 仅构建；正式发布使用 `release`。失败时不清理旧包，安装替换后的启动检查失败会恢复原安装。保留范围不涉及用户配置、监控历史、源码或 REA 文档；桌面快捷方式目标保持稳定。

### 账号保存目录

在设置页的音乐律动板块选择私人账号保存文件夹。新位置在下次完全退出并重开后生效，迁移完成前使用原位置。该文件夹保存音乐元数据、系统加密票据和受保护的官方网页登录会话。迁移失败时保留原数据，设置页显示原因。平台主动撤销会话或令牌过期时需要重新登录，选择保存目录不能改变平台的有效期。账号数据绑定当前 Windows 用户，分享软件仅发送程序本身。

### GitHub 更新

右侧竖轨在发现新版时显示更新按钮。更新来自 https://github.com/M1vvl/Sonora/releases/latest 的正式 Windows 单文件发布，点击后校验 GitHub 提供的 SHA-256 摘要并关闭、替换和重新启动。启动确认超时会尝试恢复前一个程序。运行目录需要可写，下载或校验失败时保留当前程序。

仓库 `.github/workflows/windows-release.yml` 在 main 的 package.json 版本更新时构建并发布对应版本，重复版本会跳过，也支持手动运行。需要在 GitHub 仓库启用 Actions。客户端每六小时检查一次正式发布，初次启动后也会检查。
